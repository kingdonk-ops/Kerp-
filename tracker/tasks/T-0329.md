## Goal
Screens for project-level inspections and issues (user, 2026-11-21; ADR 0003 amendment 2026-11-21): capture and raise without an anchor, location and link pickers, and "Linked inspections / issues" panels on the linked records.

## Acceptance criteria
- [ ] Starting an inspection of a non-`qa_itp` template asks for no anchor; optional location picker (node search / scan-to-locate T-0154) and link pickers for asset (node/Item) and equipment (selectable entries only); material shown disabled until E-03-03; works offline like T-0130/T-0162
- [ ] Raising a project-level issue (from such an inspection, or manually in an `allows_project_level` category) shows "Project" instead of an anchor, inherits location and links from the inspection, and lets the user edit them
- [ ] Inspection and issue registers get location and link columns and filters (`location`, `linked`), and a "Project-level" filter
- [ ] Node, Item and equipment DetailPages show "Linked inspections" and "Linked issues" tabs from `inspections.service.linked_records` / `issues.service.linked_issues`, clearly marked as informational (not counted in progress)
- [ ] All strings through `t()`; 48 dp targets; component tests; e2e: pre-start with an equipment link → visible on the equipment detail
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
