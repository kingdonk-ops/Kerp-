## Goal
The heart of the one engine (SPEC-11 §2): the **field-type registry** (all types incl. measurement value+unit, signature, GPS, repeating table, calculated, instrument/calibration reference) and a **declarative expression evaluator** — choose CEL *or* JSONLogic (record the choice in an ADR) — for `visible_if`/`required_if`, calculated fields and validations. Never user scripts. Shared JSON fixture suite so a later TS port proves parity (F8).

## Acceptance criteria
- [ ] ADR in docs/decisions/ records CEL vs JSONLogic
- [ ] Registry exposes every SPEC-11 §2 field type with schema + validation
- [ ] Evaluator sandbox tests: no attribute access, no imports, function allow-list only, bounded execution
- [ ] Shared fixture files (`fixtures/evaluator/*.json`) drive the Python tests
- [ ] Calculation-cycle detection
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
