## Goal
core/fields palette: numeric, text, unit-bound measurement, photo, signature, instrument reference, calculated. One CEL evaluator shared by forms/ITP/asset schema (diff §2.1).

## Acceptance criteria
- [ ] Every field type in the shared palette
- [ ] CEL visible_if/required_if/calculated/range evaluate client+server identically
- [ ] Template JSON schema: every user-facing string (`label`, option labels, `validation.error_message`, help, section titles) accepts a plain string or a per-locale map keyed by BCP 47 tag; templates declare `default_language` (default `en`); lint rejects an empty map or a map without the default language; keys, option values and CEL are never localised (edge §2.2 amendment, TD-183)
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
