## Goal
The **Templates** menu item (user, 2026-11-21; diff §6.1; quality-and-inspection.md §Template settings): every inspection template of the project in one filterable list, "New template" from a preset, and the settings panel (area, issue category, formal, audit + scope, linked issue types) with the locked-setting rule. Field authoring opens the shared designer (E-01-03) once it exists.

## Acceptance criteria
- [ ] Execution → Templates on `RegisterPage`: name, kind, area (plain label), issue category, formal, audit (scope), status (`draft | published | retired`), revision; filters area, issue category, formal, audit, status, kind; PER-13 also sees a "Tenant library" scope
- [ ] "New template" asks one question (QA inspection, H&S check, Pre-start, Equipment check, Repair/fault, Internal audit, External audit) and opens the settings pre-set from the preset (T-0324); every setting can be changed before the first publish

- [ ] All strings through `t()`; component tests with synthetic data; e2e: create from the Pre-start preset → publish → appears filtered by area
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
