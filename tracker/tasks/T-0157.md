## Goal
TD-166 (screens): the inspector takes a photo and marks it up on the device, offline, and sees the markup on later views.

## Acceptance criteria
- [ ] Photo capture in the form stores the blob through `MediaStore` and records `captured_at` and the location when allowed (a denied permission never blocks capture)
- [ ] Annotation editor with the five shape tools, the four-colour palette, two strokes, undo and clear; touch targets ≥ 48 dp; works without network
- [ ] Annotations are saved as the v1 JSON (normalised coordinates) through the outbox; reopening renders the overlay at the right place on different screen sizes (test)
- [ ] Editing is disabled once the inspection is submitted
- [ ] All strings through `t()`; component tests for each tool
- [ ] `frontend/README.md` updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
