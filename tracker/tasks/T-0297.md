## Goal
Labs and NDT subcontractors submit their own reports, internal QA verifies them (diff §4.9 *External parties*; quality-and-inspection.md §QA verification queue).

## Acceptance criteria
- [ ] `POST /api/v1/qms/external-submissions` (external party persona of T-0296, request in its subtree): file through presigned uploads (T-0016, scanned), document kind (`ndt_report | test_certificate | calibration_certificate`), the NDT result (T-0204) or inspection request it answers
- [ ] The submission creates a verification item (T-0181 provider `external_submission`); nothing it contains changes an NDT result, weld or inspection until a QA verifier approves (test)
- [ ] The submitter sees only its own submissions and their status (`submitted | verified | rejected` with reason); never other parties' files or internal comments
- [ ] Every submission and decision audited; e-mails carry link + project code/name only (diff §4.6)
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
