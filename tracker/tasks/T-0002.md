## Notes
- Stack choices: Vite 8, React 18.3 (pinned `^18.3.1`; React Router 8 needs React 19, so
  **React Router v7** library mode), TypeScript 5.9 strict (+ `noUncheckedIndexedAccess`,
  `exactOptionalPropertyTypes`), **Tailwind v4** via `@tailwindcss/vite`, TanStack Query v5,
  Dexie 4, i18next + react-i18next (typed keys), Vitest 5 + jsdom + `fake-indexeddb`.
  Node `>=22.12` (CI Node 22). Lockfile includes linux-x64 native bindings for CI.
- Outbox: Dexie table `outbox_mutations` (master spec §1.3 name) with primary key
  `client_op_id` (consolidation §6 name — wins over master's `client_mutation_id`).
  `enqueueMutation` is idempotent on that key. Drain/replay, vector clock, conflict
  handling and the offline indicator stay in T-0126/T-0127. Local storage is Dexie/IndexedDB
  per consolidation §6 (supersedes master §1.3 SQLite/OPFS).
- `frontend/src/api/` holds only a README; `gen:api` deferred → TD-018.
- No PWA manifest/service worker → TD-019. No frontend linter in the gates → TD-020.
