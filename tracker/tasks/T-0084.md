## Goal
Make the per-project module toggle usable. Today `GET/PUT /api/v1/modules` read the project from the session's tenancy binding, which no request binds (TD-122), so both always answer 404 and the Phase 0 exit journey (T-0027) cannot toggle a module. Move the API onto the project path, bind the project with the shared `projects.service.bind_project` helper (T-0217), and guard writes with the admin capability (TD-129).

## Acceptance criteria
- [ ] `GET /api/v1/projects/{project_id}/modules` lists every loaded module in dependency order with `name`, `version`, `depends_on`, `toggleable`, `enabled` for that project; a member of the project with `V` gets 200; a non-member gets 404; another tenant's project id gets 404 (tests)
- [ ] `PUT /api/v1/projects/{project_id}/modules/{name}` with `{"enabled": bool}` requires the `admin` capability on that project (PER-09, or `system_admin` per ADR 0016): a member without it gets 403, a non-member 404 (tests)
- [ ] Unchanged semantics from T-0011, now reachable: unknown module 404; `toggleable=false` module 409 with a detail naming the module; a change that breaks a dependency 409 naming the module to change first; each change appended to the project's `project_modules` audit chain with the caller's user id; enable listeners run (validation copies module default rule sets) (tests with a test-only toggleable module in the test package, never in `app/modules/`)
- [ ] The module gate (`module_gate`) still answers 404 for a disabled module on a project-bound request (existing test kept green)
- [ ] The project-less `/api/v1/modules` routes are removed (they could never succeed); `backend/tests/test_module_toggle.py` and `test_openapi_export.py` updated without weakening any assertion; `npm run gen:api` re-run and committed
- [ ] TD-129 resolved (guard in place) and TD-122 noted as resolved for the module toggle API (the gate's project-less skip stays documented)
- [ ] `backend/app/core/module_loader/README.md` (Toggle API, Until TD-122) updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
