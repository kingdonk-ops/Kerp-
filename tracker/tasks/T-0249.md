## Goal
Let the equipment register hold fleet vehicles and plant besides calibrated instruments, so pre-starts and tagouts can target them (diff §5 *Equipment classes*). Pulls a slice of E-03-07 into Phase 1 if the user agrees (TD-412).

## Acceptance criteria
- [ ] Additive columns on `oe_equipment_asset`: `equipment_class` (`instrument | vehicle | plant`, default `instrument`), `requires_calibration` (default true for `instrument`, false otherwise), `asset_number` (fleet number, unique per project when set), `custodian_user_id` (nullable; must be a project member, else 422)
- [ ] The calibration gate (T-0112) and the `equipment.activate` cert rule (T-0260) apply only when `requires_calibration` is true (test: a vehicle without a cert can be active)
- [ ] `service.py` exposes `get_selectable(project, class=?)` (active only, never `out_of_service`, `quarantined`, `decommissioned`) and `custodian_of(equipment_id)` for other modules
- [ ] Register custom fields stay versioned (ADR 0003 §6); existing rows become `instrument` (test)
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
