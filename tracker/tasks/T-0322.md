For Pilot-0 there is no template designer (E-01-03 comes after the pilot), so we author the starting issue templates and seed them as tenant defaults (user, 2026-11-21; issues.md §2).

- [ ] Tenant-default seed (versioned YAML in the `issues` module, synthetic wording only) with published punch and NCR templates for the categories `painting`, `blasting`, `civil`, `mechanical`, `welding` (10 templates) and an internal audit finding template (category `general`, `default_origin = internal_audit`, `internal` + `excluded`) for punch and NCR

- [ ] A new project gets project copies and a default template per category × type for these templates (test)
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
