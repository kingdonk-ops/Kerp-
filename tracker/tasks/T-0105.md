## Goal
Primavera XML variant of the P6 parser (XER + XML are the formats now, TD-077); unmatched-row linking so schedule updates never sever existing inspection/work-anchor ties (diff §3). Backend for the Unmatched-Row Linking Screen.

## Acceptance criteria
- [ ] Primavera XML parses through the same staging/idempotency path as `.xer` (p6 spec §3)
- [ ] Unmatched rows are surfaced for manual linking, never auto-dropped or auto-reparented (p6 spec §5.1)
- [ ] Linking an unmatched row targets a node on the `schedule_link` level and preserves existing inspection/work-anchor ties on the target node (p6 spec §6, §11 test 6)
- [ ] Approving a link calls `run_checks` with the locked default rule set `p6.link.approve` (p6 spec §5.5, TD-114 default)
- [ ] `asset_management` `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
