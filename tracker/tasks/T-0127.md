## Goal
Dexie transactional outbox keyed on client_op_id; optimistic UI; idempotent drain on reconnect (diff §6).

## Acceptance criteria
- [ ] Writes queue offline and drain idempotently
- [ ] Offline indicator reflects queue depth
- [ ] The outbox and local records are written through the client storage contract (`RecordStore`, `OutboxStore`, `MediaStore`, `wipe()`, diff §6.2); Dexie is one adapter of it and no app code imports Dexie directly (TD-161)
- [ ] A reusable contract test suite runs against the Dexie adapter (and later the SQLCipher adapter, T-0142)
- [ ] Queued work survives the offline window (tenant setting, up to 14 days; tests with a fake clock at 14 days)
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
