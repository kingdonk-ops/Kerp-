## Goal
Machine access for integrations, alongside the webhooks of E-05-07 (diff §4.9 *API keys and service accounts*, ADR 0017). Authentication is T-0308, screen T-0309.

## Acceptance criteria
- [ ] Additive core column `auth_user.account_type` (`human | service`, default `human`; ADR 0017 in force): service accounts have no password, SSO link, magic link, PIN, device or invite, cannot sign in interactively (tests per path), and are excluded from seats, presence, lobby, broadcasts and the directory's human counts
- [ ] `POST/GET/DELETE /api/v1/admin/service-accounts` (`system_admin`); memberships through the existing admin APIs, never PER-09, PER-15 or a hold-authority persona's `A`/`S` (T-0308 strips them anyway)
- [ ] A service account can never hold an admin grant (ADR 0017 §4, ADR 0016): the admin-grant API refuses any grant (incl. `system_admin`) to an `account_type = service` user with 422 `SERVICE_ACCOUNT_NOT_GRANTABLE`, audited, nothing written (test); service accounts are `is_internal = false` (T-0295 boundary applies, intended); SCIM (T-0299) never matches, updates or deactivates them (test with a SCIM `userName`/`externalId` equal to a service account's)
- [ ] `oe_identity_api_key` (`BaseRecordMixin` + tenant RLS): service account, name, `key_prefix`, `key_hash` (SHA-256 of 256-bit random), `scopes` (`read`, `write`), `project_ids` (empty = tenant-wide), `expires_at` (required, ≤ 365 days), `last_used_at`, `revoked_at`, `revoked_by`
- [ ] Create returns the key once; list never shows it; revoke takes effect at once (Redis revocation entry)
- [ ] `POST /api/v1/admin/api-keys/{id}/rotate` (`system_admin`): issues a new secret (new prefix and hash, same account, scopes, projects and expiry cap) shown once; the old secret keeps working for an overlap of at most 24 h (`rotation_overlap_until`, then refused like a revoked key) and can be revoked at once earlier; rotating a revoked or expired key → 409; audited `api_key.rotated` without either secret (tests: both secrets valid inside the overlap, old refused after it, new shown only once)
- [ ] Every create, rotate, revoke and expiry audited in `admin-system:<tenant>` (TD-438: `system_admin` manages; PER-09 lists keys touching its projects)
- [ ] Token-hash helpers shared with T-0298 (one implementation)
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
