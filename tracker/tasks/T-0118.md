## Goal
Personnel competency is a dedicated module (TD-061) and KERP holds the records (TD-101): credential/ticket/VOC records with uploaded certificates, typed by a tenant-wide qualification-type catalogue, read by the stateless `eligibility` service (T-0139) as of the inspection date.

## Acceptance criteria
- [ ] Qualification-type catalogue: name, `expires` (bool), validity period from the issue date (or none), applicable inspection categories and work-task categories; tenant-level, edited per the TD-118 decision (tenant administrator; PER-09 may add project-level types) (quality-and-inspection.md §Credentials are KERP records)
- [ ] Credential records: holder, qualification type, issue date, computed expiry (issue date + period; none when the type does not expire), number, uploaded certificate/VOC document via the storage service (T-0016)
- [ ] `service.py` exposes credential status for (person, qualification type, `as_of` date); a credential valid on `as_of` passes even if expired today; a type that expires but has no issue date fails closed (ADR 0004 Amendment C)
- [ ] The module registers its provider with the `eligibility` seam (consumed by T-0139); an expired credential blocks assignment with a reason
- [ ] Register columns are extensible through a versioned register-type JSONSchema (`custom_fields`) (ADR 0003 §6)
- [ ] Tables use `BaseRecordMixin` and have RLS (project-scoped records; tenant-level catalogue)
- [ ] `credentials` `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
