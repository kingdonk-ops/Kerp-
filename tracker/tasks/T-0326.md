## Goal
Project-level issues (user, 2026-11-21; resolves TD-443; issues.md §3.1, §6): audit and H&S findings without an anchor or work anchor, with an optional informational location and links, that never block work completion and whose MDR effect is scoped by project or location.

## Acceptance criteria
- [ ] `oe_issues_issue` allows neither `anchor_node_id` nor `anchor_item_id` (then `anchor_role`, `work_anchor_node_id` NULL) only when the issue is raised from a project-level inspection (checked through the inspections service) or its template's category has `allows_project_level`; otherwise the T-0312 anchor rule applies (422) (tests)
- [ ] `oe_issues_category.allows_project_level` (bool, default false, additive); seed revision adds the categories `health_safety`, `vehicle`, `equipment`, `pre_start` (non-discipline categories, issues.md §2) and sets `allows_project_level` true for `audit`, `health_safety`, `vehicle`, `equipment`, `pre_start` (new library revision, never forced on project copies)
- [ ] Nullable `location_node_id` and `oe_issues_link` (`BaseRecordMixin` + project-scoped RLS; `target_kind` `node | item | material | equipment`, `target_id`) through the same link-target providers as T-0325 (no cross-module table access); location and links only on project-level issues (422 otherwise)
- [ ] `open_issues` / `gate_facts`: project-level issues never appear in `work_anchor.complete`, hydrotest release, `weld.accept` or `closeout.final_handover` facts (tests)
- [ ] MDR facts and `mdr_register(scope)`: an open project-level issue with `mdr_effect = blocks` and no location is in every MDR scope of the project; with a location only in scopes that overlap it (location = scope node, inside it, or an ancestor; through the `asset_management` service) (tests for each case)
- [ ] Search `GET /api/v1/issues?location=&linked=<kind>:<id>`; `issues.service.linked_issues(kind, id)` for the linked record's detail; internal issues stay hidden from `is_internal = false` callers there too (test)
- [ ] Offline raise of a project-level issue works like T-0312 (number at sync)
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
