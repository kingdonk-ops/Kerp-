## Epic
Send an issued work plan for review: recipients from the project distribution matrix
(communication formats × contacts, To/Cc), an email describing the planned work with the
revision's PDF pack, a magic link for people without an account and a portal link for
everyone else. The portal layout depends on the participant's client role (stats by resource
group, hours by RSW, start/end dates, work packs/RSWs, issues per RSW/asset, timeline,
calendar, kanban). Anyone with access can comment on the whole plan or any area; every linked
participant is notified; only users with edit rights change the plan. Approval builds up over
one or more review sessions with recorded attendance; when every required approver has
approved the same revision the plan is approved and added to the schedule; absent approvers
can be overridden with a reason. Detail and suggested breakdown in the spec §10.

Open decisions / gaps: TD-081 (external and proxy approval), TD-084 (email transport), TD-085 (distribution matrix).

**Status `needs-breakdown`:** the planner agent splits this into S/M tasks (`T-xxxx`, `epic: E-07-04`) when its phase is next. Do not implement an epic directly.
