## Goal
Thresholds become registry entries editable by System admins without a redeploy (diff §4.7 Runtime settings registry; TD-297, TD-046).

## Acceptance criteria
- [x] Code-declared `SettingDef` (key, category, type `int | float | bool | string | enum | int_list`, bounds, default, client_visible, optional deployment-config cap); registration refuses secret-like keys and types (test)
- [x] Table `oe_settings_value` (`BaseRecordMixin`, tenant RLS; additive): one live row per (tenant, key), value JSON; no row = default
- [x] The seven T-0044 settings move into the registry (data copied by the migration; `oe_settings_deployment` kept read-only until a later ADR drops it); `GET/PATCH /api/v1/settings/deployment` keeps its contract (existing tests pass unchanged)
- [x] `GET /api/v1/settings/registry` (`system_admin`): entries with value, default, bounds, category; `PATCH` per key: out of bounds or over the deployment cap → 422 (e.g. `offline_window_days` 15), never clamped
- [x] Entries of diff §4.7's table declared here when their consumer exists (uploads size and URL TTL now); the others are declared by their consumer tasks (T-0140, T-0156, T-0162, T-0167, T-0169, T-0174)
- [x] Values cached in Redis; a change publishes an invalidation on pub/sub and every API/worker process drops its cache at once (test with two subscribers); audit `{key: [old, new]}` with actor
- [x] `GET /api/v1/settings/deployment-config` (`system_admin`): the read-only deployment configuration of §4.7 (refresh hours, PIN idle, lockout schedule, region, mail sender, scanner, AI provider) — non-secret values only (test that no secret field of `Settings` can appear)
- [x] Module `README.md` and docs updated
- [x] Category `uploads_media` declares `tablet_proxy_max_px` (int, 1280, 640–2560), `tablet_proxy_quality` (int, 72, 40–95), `report_image_max_px` (int, 1024, 480–2048), `report_image_quality` (int, 68, 40–95), read by T-0247 (user addendum 2026-11-21, pasted against 'T-0075' = this task)
- [x] All quality gates green (see CLAUDE.md §Quality gates)
