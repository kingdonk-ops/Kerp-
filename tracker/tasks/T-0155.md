## Goal
TD-163 (client side): the inspector scans a tag and lands on the Item and its inspections, offline included.

## Acceptance criteria
- [ ] A scanner adapter interface with an Android implementation (camera barcode/QR through a native plugin; NFC UID through a Capacitor NFC plugin) and a web implementation (browser barcode detection where available, else manual entry; no NFC); app code depends only on the interface
- [ ] Chosen plugins have permissive licences (no GPL); the licences are recorded in `frontend/README.md`
- [ ] Offline, lookup runs against identifiers of downloaded Items in `RecordStore`; online, a local miss calls `GET /assets/items/lookup`; not found shows a clear message and the manual tag search
- [ ] A hit opens the Item with its downloaded inspections
- [ ] Online, PER-06/PER-09 can assign an unknown scanned code to an Item (T-0154 API)
- [ ] Scanner code is lazily loaded; 48 dp targets; all strings through `t()`; tests use a fake scanner
- [ ] `frontend/README.md` updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
