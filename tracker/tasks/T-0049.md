## Goal
Mark internal staff automatically (product owner, 2026-11-14; diff §4.1 Internal staff) so the lobby list can be limited to them and external users reach projects only by code or invite.

## Acceptance criteria
- [x] Users gain `is_internal` (boolean, default false) and nullable `entra_oid` / `entra_tid` (unique per tenant on `entra_oid`, used by T-0054): additive migration on the auth users table, described in `app/core/auth/README.md`
- [x] Short ADR in `docs/decisions/` for this core-table change (CLAUDE.md §6: core-table changes need an ADR): the new user columns, the derivation rule (member Entra link or listed domain, recomputed at sign-in, never from input) and why `entra_oid` is the stable link
- [x] `KERP_INTERNAL_EMAIL_DOMAINS` (deployment configuration, comma-separated, normalised to lower case, exact domain match, no wildcards; empty = no domain rule) is validated at startup (rejects entries containing `@`, spaces or `*`)
- [x] `is_internal` is recomputed at account creation and at every successful sign-in (password, magic link, and later SSO): true when the account is linked to a **member** (non-guest) account of the company Entra tenant (`entra_oid` set; T-0054 links members only and refuses guests) or the e-mail domain is on the list; false otherwise (removing a domain takes effect at the user's next sign-in)
- [ ] The flag is never accepted from request input (user create/update schemas reject it with 422) and never read from token claims; it is exposed read-only on `/auth/me` and in the admin user list (T-0014)
- [x] Other modules read it only through an auth-service helper (e.g. `is_internal_user(user_id)`), never the users table (CLAUDE.md §6)
- [x] The flag grants no capability: a test shows an internal user without a membership still gets 404 on a project
- [x] Tests: domain match (case-insensitive), subdomain not matched, empty list, Entra-linked account internal regardless of domain, recompute on sign-in after the list changes
- [x] `app/core/auth/README.md` and deploy docs updated
- [x] All quality gates green (see CLAUDE.md §Quality gates)
