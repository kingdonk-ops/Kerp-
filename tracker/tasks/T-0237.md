## Goal
Move archives between storage classes and download them (documents-and-mdr §Registry, tiers and download).

## Acceptance criteria
- [ ] `PUT /api/v1/admin/system/archives/{id}/storage-class` (`system_admin`): S3 `CopyObject` onto the same key with the new class; registry updated only after success; audited
- [ ] Shared content-access gate `archive.service.require_content_access(session, archive, caller)` (reused by T-0239 and T-0240): `system_admin` (else 403) **and** a membership on the archived project, else 404 — live project: a live membership; deleted project: the caller is in `admin.service.memberships_at_deletion(session, project_id)` (documents-and-mdr §Access, TD-396)
- [ ] `admin.service.memberships_at_deletion(session, project_id) → dict[user id, set[Grant]]`, built on `app/core/auth/memberships.py`: the project's soft-deleted membership rows filtered to the `"<user id>:<persona>"` pairs of the `revoked_memberships` payload of the latest `delete` entry in the `project:<id>` chain, which `projects.service.deletion_revoked_memberships(session, project_id)` (new, projects module) returns; no module reads another's tables or the ledger directly
- [ ] Test: a membership removed **before** the deletion (soft-deleted, not in `revoked_memberships`) is not returned by `memberships_at_deletion` and does not pass the gate; a membership re-granted and then revoked by the deletion is returned
- [ ] `GET .../{id}/download` (through the gate above): short-lived presigned GET for `STANDARD`, `GLACIER_IR` or a `restored_temp` copy; `DEEP_ARCHIVE` → 409 `ARCHIVE_NOT_RESTORED`
- [ ] Test: a `system_admin` without a membership on the archived project gets 404 on download (no URL issued); with a membership (e.g. self-granted PER-09, audited, T-0014) it gets the URL
- [ ] Test: after the project is deleted, a former member (a membership revoked by the deletion) can download its archive; a `system_admin` who was not a member at deletion gets 404
- [ ] Storage-class change needs `system_admin` only (it moves the object without exposing content)
- [ ] Tests against a fake S3 (storage class reflected in the registry)
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
