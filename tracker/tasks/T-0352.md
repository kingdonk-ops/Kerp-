## Goal
Split out of T-0104 (PR #192 review): read an uploaded XER into staging, nothing more. A pure-stdlib streaming parser
(`backend/app/modules/asset_management/p6/xer.py`) and the staging tables of the `oe_p6_*` mirror, per
`docs/spec/modules/p6-xer-format-and-mapping.md` §1–§4 and §6. Grammar mapping, placeholders, diff and commit stay in T-0104.

## Acceptance criteria
- [ ] `oe_p6_import` table (RLS, BaseRecordMixin) and its status flow `uploaded → [awaiting_project_choice →] parsed` / `failed` (P6 spec §4); `previewed`/`committed`/`discarded` are added by T-0104
- [ ] `POST /projects/{id}/p6/imports` stores the original (sha256, immutable; same file twice = no-op returning the earlier import) and enqueues the parse on the SAQ **batch** queue (not inline); `GET …/imports/{import_id}` returns status, summary and parse errors
- [ ] SAQ batch parse job: tokenise → stage in one transaction; a failed parse leaves no staging rows (P6 spec §3)
- [ ] Tokeniser per XER spec §1–§2: columns by name, `""` → `"`, `0x7F` handling, `1899-12-30` → NULL, `Decimal` numbers, limits, `source_line` on every staged row
- [ ] Encoding pre-pass (BOM / strict UTF-8 over the stored bytes, else cp1252 with a replacement count), then line-by-line decoding
- [ ] Fatal tables (`PROJECT`, `PROJWBS`, `TASK`, `TASKPRED`) fail the import on a malformed row; other tables drop the row with a warning (XER spec §2)
- [ ] Multi-project files stop in `awaiting_project_choice` with `summary.projects`; `POST …/imports/{id}/select-project` stages the chosen project (XER spec §1, P6 spec §10)
- [ ] Staging rows per XER spec §6: `oe_p6_activity_version` (with `activity_id = NULL`), `oe_p6_wbs_stage`, per-import `oe_p6_calendar`, code/UDF types, resources and assignments without cost, relationships incl. `external_pred_task_code`
- [ ] Never stored: costs, rates, currencies, `FT_MONEY` UDFs, P6 user names, ERMHDR login, resource e-mail/phone (test X7)
- [ ] Synthetic fixture generator `backend/tests/fixtures/p6/make_xer.py` and the fixtures of XER spec §7 (no real schedule strings)
- [ ] Tests X1–X8 and X12 of XER spec §8; X13 in the dedicated `perf` job
- [ ] `asset_management` `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
