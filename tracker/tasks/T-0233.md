## Acceptance criteria
- [ ] New module `archive` (manifest, models, router, service, schemas, README); table `oe_archive_project_archive` (`BaseRecordMixin`, tenant RLS) with the fields of the spec section
- [ ] `POST /api/v1/admin/system/archives` `{project_id}` (`system_admin`, else 403; any live project of the tenant, no membership needed, documents-and-mdr §Access, ADR 0016) creates a `queued` row and enqueues the `batch` build job (T-0234); list and detail endpoints

- [ ] Bucket and region from deployment configuration only (no hard-coded bucket or region)
