## Goal
TD-218 (palette): add `video`, `audio` and `barcode` to the shared field-type registry.

## Acceptance criteria
- [ ] `video` value: list of `{attachment_id, sha256, captured_at, geo, duration_s, poster_attachment_id}`; at most 3 clips, 60 s, 100 MB, MP4 H.264/AAC, ≤ 720p (planner defaults)
- [ ] `audio` value: list of `{attachment_id, sha256, captured_at, duration_s}`; at most 3 notes, 5 min, 10 MB, AAC/M4A (planner defaults)
- [ ] `barcode` value: `{value, kind: barcode|qr, source: scanned|manual}`; CEL rules can reference `value`
- [ ] Limits live in one registry constant shared with the client through the conformance fixtures; violations → 422 for that path (a failed mutation result through sync)
- [ ] Answers are read-only after submit like other fields
- [ ] `forms` `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
