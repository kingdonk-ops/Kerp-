## Goal
A reconciliation check that proves the team-derived grants in the core membership store match
the teams tables exactly (ADR 0008, Reconciliation). It reports all drift, including **excess
access**, and repairs it on request. It is the safety net behind T-0013's in-transaction sync.

## Acceptance criteria
- [ ] `teams.service.reconcile(session, *, fix: bool = False) -> ReconcileReport`, runnable only in a `system_admin` tenant-level session, plus a CLI entry point `teams reconcile [--fix]` (the project's CLI pattern, a non-zero exit when drift is found and not fixed)
- [ ] Expected state: for every non-deleted link of a non-deleted team, the set of `(user_id, linked_project_id, persona, site_node_id)` over its non-deleted members. Actual state: T-0073's `team_link_grants(session)` (full tuples, every link id with live derived rows). Members with deactivated accounts count as expected, matching ADR 0008's "deactivation leaves derived rows"
- [ ] The report lists, per link id: **missing** tuples (expected, not stored), **excess** tuples (stored, not expected: covers a wrong persona, site or project after an unsynced re-role or site change, and removed members), and **orphan link ids** (live derived rows whose link id is unknown or deleted in the teams tables)
- [ ] `fix=True`: live links get `sync_team_link_grants` with the expected state (`confirm_sod=True`, since the combination was confirmed when the link was made; the audit entry records `reason: reconcile`). Orphans get `revoke_team_link_grants`. The report says what was repaired
- [ ] Reads the teams tables only inside the teams module and the core store only through the T-0073 API (CLAUDE.md §6)
- [ ] Tests:
  - A clean state reports no drift
  - A **persona mismatch** (a derived row edited to PER-02 behind the sync's back) is reported as excess + missing, and `--fix` restores the link's persona
  - An **orphan link id** (derived rows with a `via_team_link_id` not in the teams tables) is reported, and `--fix` revokes it so the user loses that access
  - A missing tuple (a member whose sync was skipped) is reported and fixed
  - A non-`system_admin` session is refused
- [ ] Module/README.md and docs updated (teams README: reconcile, when to run it)
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
