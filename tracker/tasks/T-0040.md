## Goal
Users find lobby-visible projects (internal staff only) or enter a project code, as the entry point to an access request (diff §4.1). The request lifecycle itself is T-0050.

## Acceptance criteria
- [ ] Projects gain `visible_in_lobby` (default false, additive migration); only PER-09 of that project (or a `system_admin`) can change it (master §4.1 amendment)
- [ ] `GET /api/v1/lobby/projects` returns id, code and name of lobby-visible projects only, and only to internal users (`is_internal`, T-0049; product owner, 2026-11-14); an external user gets 403 with `code: LOBBY_INTERNAL_ONLY` and no project data; it reads through a narrow path (security-definer function or security-barrier view) that itself returns no rows for a non-internal caller (defence in depth, edge §6 amendments), and the membership-based `projects` policy is not widened; PostgreSQL test as `kerp_app` shows a non-member still cannot fetch the full project row (edge §6 amendments)
- [ ] `GET /api/v1/lobby/projects/by-code/{code}` returns the one project with that exact code (id, code, name) whether or not it is lobby-visible, to internal and external users alike; unknown code → 404; rate-limited per user and deployment-wide, per-client-IP limits follow TD-138 (user, 2026-11-13; TD-202: a code never grants access by itself); the response carries a short-lived **lookup ticket** (signed, bound to user and project, 15 minutes, planner default) that T-0050 requires on a user's **first** request for a project when the user is external or the project is not lobby-visible; re-requests after an earlier rejected or withdrawn request need none (diff §4.1)
- [ ] Both endpoints mark projects the caller already belongs to (effective access, incl. team-derived grants once T-0073 lands) so the UI can open them instead of offering a request
- [ ] Tests: internal user lists lobby-visible projects only; external user gets 403 on the list but finds a non-visible project by code; a code lookup never creates a membership
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
