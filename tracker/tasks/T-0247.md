## Goal
Every image upload keeps its untouched original and gets a tablet proxy and a report rendition, so tablets sync and PDFs embed small images while exports keep full quality (quality-and-inspection.md §Image derivatives; user addendum 2026-11-21).

## Acceptance criteria
- [ ] After a clean scan of a JPEG, PNG or WebP file, a `batch` SAQ job writes the tablet proxy (longest edge <= tablet_proxy_max_px, default 1280, progressive JPEG, quality tablet_proxy_quality, default 72) and the report rendition (<= report_image_max_px, default 1024, quality report_image_quality, default 68); both EXIF auto-oriented, EXIF (incl. GPS) stripped, sRGB
- [ ] The original stays at its content-addressed key, byte-identical and SHA-256 verified; nothing ever overwrites it (test compares bytes before and after)
- [ ] Derivative keys `derivatives/{tenant}/{project}/{module}/{sha256}/{tier}_{max_px}_{quality}.jpg` (TD-408); reused when the same content and parameters exist
- [ ] New table `oe_uploads_derivative` (`BaseRecordMixin`, project-scoped RLS; additive): file id, tier `tablet_proxy | report`, key, size_bytes, width_px, height_px, parameters; nullable `width_px`, `height_px` on `oe_uploads_file` (additive)
- [ ] An image file becomes `available` only when the scan passed and both derivatives exist; an undecodable image → `rejected` / `image_decode_failed`, over the pixel cap (decompression-bomb guard, planner default 50 MP) → `rejected` / `image_too_large`; transient errors retry; T-0215's stuck rule still applies
- [ ] `uploads.service` exposes `derivative(file_id, tier)` and presigned GETs per tier for other modules (sync T-0147, forms, inspections T-0158, archive)
- [ ] Parameters read through the settings service from the registry entries of category `uploads_media` (T-0230) once that task is done; until then the shipped defaults above come from one constants module (no literal elsewhere)
- [ ] Pillow (or pyvips) is imported lazily inside the job and added to the T-0022 heavy-import lint list; the lint test proves a module-level import fails
- [ ] Tests with synthetic images: EXIF-rotated JPEG, PNG with alpha, WebP, a tiny image (no upscaling), a corrupt file, an over-cap image
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
