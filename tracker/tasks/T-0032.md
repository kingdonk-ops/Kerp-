## Acceptance criteria
- [ ] New scheduled workflow (weekly cron + `workflow_dispatch`) re-runs `uv pip compile --upgrade` for every `backend/requirements*.in` → `.lock` and opens (or updates) one PR to `dev` when a lock changed; no third-party app is added; least-privilege `permissions` (TD-047)
- [ ] Every `uses:` in `promote.yml` and `review-gate.yml` is pinned to a full commit SHA with a version comment; `actions/checkout` sets `persist-credentials: false` wherever the job does not push (TD-048)
- [ ] The `postgis/postgis` and `redis` service images in `ci.yml` are pinned by `@sha256:` digest with the tag in a comment (TD-048)
- [ ] `backend-publish` pushes the image that `backend-image` smoke-tested, identified by digest (exported artifact or registry digest hand-off), not a rebuild; the pushed digest equals the tested digest and is printed in the job summary (TD-051)
- [ ] `ci.yml` passes `${{ github.base_ref }}` through `env:` instead of interpolating it into `run:` (PR #16 review, docs/pr-suggestions.md P9)
- [ ] Dead "detect not green" override in `scripts/ci_gate.py` removed or covered by a test (PR #18 review, P9)
- [ ] Workflow lint (`actionlint` or equivalent) passes on the changed workflows
- [ ] `.github/` README or `docs/WORKFLOW.md` updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
