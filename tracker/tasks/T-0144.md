## Goal
TD-168 decision 5a: push notifications as a second channel behind T-0019's channel interface.

## Acceptance criteria
- [ ] An `fcm` channel implements the T-0019 channel interface; it is enabled by deployment configuration and off by default in development and tests
- [ ] The Android app registers its FCM token against its device record (T-0043); revoked devices get no pushes and their tokens are deleted
- [ ] Assignment and return notifications are pushed to the recipient's active devices; payloads carry ids and a title only, no record content
- [ ] FCM credentials come from deployment secrets; tests use a fake FCM client
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
