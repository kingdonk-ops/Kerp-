## Goal
The owning modules publish the events the ITP alignment watchdog listens to, through the E-05-07 outbox (ADR 0007: row in the domain transaction, relayed by the SAQ worker, at-least-once, idempotent handlers).

## Acceptance criteria
- [ ] `scope_changes` emits `scope_change.agreed` and `scope_change.implemented` (change-of-scope.md §5) with project, scope change id, anchor node id, agreed line summary
- [ ] P6 import (T-0104) emits `p6.import.committed` with project, import id and the anchors whose linked activities were added, removed or changed
- [ ] `asset_management` emits `asset.node.updated` (attribute or level changes relevant to ITP rules: code, level, custom_fields keys) and `tasks` emits `task.created` (E-04-07)
- [ ] Each event is written by the owning module's `service.py` in the same transaction as the change; versioned payload schema; contract test per event
