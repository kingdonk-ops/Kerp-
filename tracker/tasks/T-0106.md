## Goal
Export progress actuals keyed on Activity ID; re-import into P6 is non-destructive (round-trip preserves existing inspection/work-anchor ties). P6 activities link to the level with the `schedule_link` role (ADR 0003).

## Acceptance criteria
- [ ] Export keys actuals on `external_activity_id` (Activity ID) (p6 spec §10)
- [ ] Actuals are read from the node on the `schedule_link` level and its work-anchor node by role; no level name (e.g. "RSW") is assumed in code (p6 spec §5.5, asset-and-tagging.md §Anchor invariants)
- [ ] Round-trip export→re-import preserves inspection/work-anchor ties and does not duplicate nodes (p6 spec §11)
- [ ] The export is built behind a format interface so the fragnet variant of ADR 0006 can be added later without changing the actuals export
- [ ] `asset_management` `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
