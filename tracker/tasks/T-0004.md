## Notes
- `backend/Dockerfile`: `build` stage (runtime deps into `/opt/venv` from `requirements.lock`; wheel built by hatchling from `requirements-build.lock` in a throwaway venv) -> `runtime` stage copies only `/opt/venv`, `USER 10001:10001` (created `kerp` user), `EXPOSE 8000`, stdlib-only `HEALTHCHECK` on `/health`, CMD `uvicorn app.main:create_app --factory --host 0.0.0.0 --port 8000`. Every `pip install` uses `--only-binary=:all:`; locks with `--require-hashes`; `pip check` in the build stage.
- Reproducibility (addresses TD-017): hashed locks `backend/requirements.lock` (runtime only, no dev deps) and `backend/requirements-build.lock` (from `requirements-build.in` = `[build-system].requires`), generated by `uv pip compile ... --python-platform x86_64-manylinux_2_28 --generate-hashes --only-binary :all:`; regeneration documented in `backend/README.md`. The local dev install stays unlocked.
- Base image `python:3.12-slim-bookworm` pinned by tag only (no digest): digest pinning without automated refresh would freeze security patches -> TD-028. amd64 only -> TD-029.
- Image sets `KERP_ENVIRONMENT=production` by default (HSTS on); override per deployment.
- `.dockerignore` is an allowlist (plus explicit excludes for `.venv`, tests, caches, `.env*`).
- `backend/tests/test_container.py` (no Docker needed) parses the Dockerfile/.dockerignore/locks: multi-stage, `--only-binary=:all:` on every pip install, `--require-hashes` on both locks, numeric non-root created `USER` in final stage, exec-form CMD, healthcheck, no `.env`/whole-context COPY, every pin hashed, lock satisfies `pyproject` dependencies and build-system. Mutation-checked locally.
- CI `backend-image` job (needs `detect`, in `ci-gate.needs`; job-level `packages: write`): buildx + GHA cache, load + smoke test (uid != 0, `/health` ok, Docker health `healthy`) on every run; on `push` (dev/main) logs in to GHCR with `GITHUB_TOKEN` and pushes `ghcr.io/kingdonk-ops/kerp-backend:<short-sha>` and `:<branch>`. No Docker on the dev machine: the image build itself is proven only by CI; the pip/hatchling/uvicorn steps were simulated locally in a Python 3.12 venv.
