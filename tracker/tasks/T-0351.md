## Goal
Hardening only (product intake 2026-11-22 (3), item 10; planner default; user to confirm): CI produces a CycloneDX software bill of materials (SBOM) for the backend and frontend on every run, and `docs/security/` gets a short controls self-assessment and a "records and retention by data class" table that the team can use to answer client security questionnaires. Adds a job; removes, skips or weakens nothing.

## Acceptance criteria
- [ ] New CI job `sbom` (in `.github/workflows/ci.yml`) generates CycloneDX JSON SBOMs for `backend/` (from the locked Python dependencies) and `frontend/` (from `package-lock.json`) with pinned tool versions, actions pinned to commit SHAs and `persist-credentials: false`, and uploads them as workflow artifacts; no network write, no secrets
- [ ] The job is additive: no existing job, step, gate, threshold or `needs` edge is removed or loosened; whether `ci-gate` requires `sbom` is decided in the PR (planner default: required, so a broken SBOM is noticed) and `scripts/ci_gate.py` plus its tests are updated to match
- [ ] `scripts/tests/test_workflows.py` (or an equivalent stdlib test) checks the job exists, uses pinned actions and generates both SBOMs
- [ ] `docs/security/controls-self-assessment.md`: a short table of controls with status and evidence links (tenant isolation and RLS, authentication and sessions, SSO, rate limits and lockouts, audit ledger, encryption in transit and at rest, upload scanning, backups and restore, dependency and SBOM management, secrets handling, logging and scrubbing, AI data use); every claim points at the spec section, ADR, task or code path that proves it; gaps say "open" with the TODO id
- [ ] `docs/security/records-retention.md`: a table "records and retention by data class" (data class, examples, where stored, retention, deletion or purge mechanism, legal hold, erasure behaviour) built from TD-175, diff §4.11 (AI assurance record), quality §Signing attestation (retention vs erasure) and the project archive; finished job rows link TD-531 (no purge yet) and every other undecided retention says "open" with its TODO id
- [ ] Synthetic or public facts only; no client names, addresses, real hostnames or secrets
- [ ] Docs updated: `docs/WORKFLOW.md` describes the SBOM job and where its artifacts are; `docs/security/` holds the two documents above
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
