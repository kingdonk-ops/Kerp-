## Goal
ADR 0003 Amendment 2: one tree plus named collections linked to nodes many-to-many (work plans,
ADR 0006, are collections).

## Acceptance criteria
- [ ] `oe_asset_collection` (`kind`, `code`, `name`, optional `window_start`/`window_end`; `code` unique per project + kind) and `oe_asset_collection_member` (unique `(collection_id, node_id)`), both `BaseRecordMixin` + project RLS (asset-and-tagging.md §Collections)
- [ ] Built-in kinds `job_pack`, `shutdown_window`, `test_pack`, `work_plan`; a project may add kinds
- [ ] CRUD + add/remove members; a node can be in several collections; membership changes never touch `parent_id` / `tree_path` (test)
- [ ] `GET /assets/collections/{id}/nodes` and `GET /assets/nodes/{id}/collections`
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
