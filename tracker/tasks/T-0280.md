## Goal
A System admin starts and ends a support impersonation from the user directory, and can never forget they are in one (diff §6.5, edge spec §5 *Support impersonation*).

## Acceptance criteria
- [ ] Admin → Users (T-0246) row and user-detail action "Login as user (support)": shown only to `system_admin`, hidden for deactivated users and for `system_admin` targets; reason modal (required, ≤ 500 characters) stating the time limit, that actions taken are recorded under the target's name and audited as impersonated, and that the target is e-mailed when the session ends
- [ ] On start the SPA keeps the admin's own session (access token in memory, refresh cookie untouched), switches to the impersonation token, reloads `me`, projects, personas and capabilities, and lands as the target would
- [ ] Persistent high-contrast banner on every screen (not dismissible, above the top bar, also on phone widths): "Viewing as {target_name} ({target_email}) — impersonated by {admin_name} · {remaining} remaining" + "Exit impersonation"; for PER-15 targets (read-only session, ADR 0015 §9) it also says "read-only"
- [ ] Exit calls `/auth/impersonation/exit`, discards the impersonation token and resumes the admin session on Admin → Users; on expiry or any 401 of the impersonation token the same hand-back happens with a notice
- [ ] Option (a): ordinary actions stay enabled and work as the target; actions the guard forbids (A/S authority, signing, co-sign, inspection submit/approve, hold release, overrides, credential/device/grant changes, project creation; every mutation for PER-15 targets) are disabled while impersonating, and a `403 IMPERSONATION_ACTION_FORBIDDEN` is shown as a clear inline message
- [ ] Offline storage: nothing of the impersonated session is written to IndexedDB/Dexie or the offline download (T-0161); the field app never offers impersonation
- [ ] All strings through `t()`; component tests and an e2e journey (start, banner, an allowed edit saved as the target, a forbidden action, exit)
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
