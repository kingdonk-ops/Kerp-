## Goal
Credentials for Entra ID SCIM provisioning (diff §4.9 *SCIM provisioning*, ADR 0017). Endpoints T-0299, screen T-0300.

## Acceptance criteria
- [ ] Table `oe_identity_scim_token` (`BaseRecordMixin` + tenant RLS): name, `token_prefix` (first 8 chars, display), `token_hash` (SHA-256 of a 256-bit random token), `expires_at` (default 365 days, max 730), `last_used_at`, `rotated_from_id`, `revoked_at`, `revoked_by`
- [ ] `POST/GET /api/v1/admin/scim-tokens`, `POST /{id}/rotate`, `POST /{id}/revoke` (`system_admin` only, else 403): the clear token is returned once at create/rotate and never again; rotation keeps the old token valid for 24 h (TD-437); all audited in `admin-system:<tenant>` without the token
- [ ] SCIM authentication (ADR 0017): tenant bound from `KERP_DEFAULT_TENANT_ID` before any lookup, then the hash looked up under tenant RLS (no bypass role, no `SECURITY DEFINER`); constant-time compare; missing, unknown, expired or revoked token → the same 401; `last_used_at` throttled to once per minute
- [ ] SCIM tokens work only on `/scim/v2/*`; JWTs are refused there and SCIM tokens everywhere else (contract test)
- [ ] Rate limit per token (default 120 requests/minute, 429 with `Retry-After`); `Authorization` headers scrubbed from logs and Sentry (test)
- [ ] Feature off unless `KERP_SCIM_ENABLED=true` (deployment config): routes answer 404 when off
- [ ] Security tests: token never in any response after creation, hash not reversible, replay after revoke, cross-tenant impossible (wrong tenant row never visible)
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
