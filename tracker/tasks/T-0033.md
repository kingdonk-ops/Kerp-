## Goal
Migrations must replay exactly the DDL that shipped (TD-060 decision): each revision inlines the
SQL that `rls_policy_sql` / `ledger_guard_sql` produced at the time, and a test fails when the live
helpers drift from what the latest revision applies.

Also close the CI follow-ups decided on 2026-11-10 (absorbed from T-0032): automate the `backend/requirements*.lock` refresh (TD-047), pin the remaining workflow actions and CI service images (TD-048), and publish the exact image that passed the smoke test instead of a rebuild (TD-051). Both halves are platform hardening with no product code; they touch disjoint files (`backend/migrations/` + core READMEs vs `.github/` + `scripts/ci_gate.py`).

## Acceptance criteria
- [ ] Migrations `0001` and `0002` (and any later revision on `dev` when this lands) no longer import `rls_policy_sql` / `ledger_guard_sql`; they contain the frozen SQL strings
- [ ] A test compares, per table, the frozen DDL of the newest revision that touches it with the current helper output and fails on any difference, naming the table and telling the author to add a new migration
- [ ] `alembic upgrade head` on a fresh PostgreSQL database produces the same policies, grants and triggers as before (existing RLS and ledger tests unchanged and green)
- [ ] `backend/app/core/tenancy/README.md` and `backend/app/core/audit/README.md` describe the new convention (replace the "call the live helper" instruction)
- [ ] New scheduled workflow (weekly cron + `workflow_dispatch`) re-runs `uv pip compile --upgrade` for every `backend/requirements*.in` → `.lock` and opens (or updates) one PR to `dev` when a lock changed; no third-party app is added; least-privilege `permissions` (TD-047) — from T-0032
- [ ] Every `uses:` in `promote.yml` and `review-gate.yml` is pinned to a full commit SHA with a version comment; `actions/checkout` sets `persist-credentials: false` wherever the job does not push (TD-048) — from T-0032
- [ ] The `postgis/postgis` and `redis` service images in `ci.yml` are pinned by `@sha256:` digest with the tag in a comment (TD-048) — from T-0032
- [ ] `backend-publish` pushes the image that `backend-image` smoke-tested, identified by digest (exported artifact or registry digest hand-off), not a rebuild; the pushed digest equals the tested digest and is printed in the job summary (TD-051) — from T-0032
- [ ] `ci.yml` passes `${{ github.base_ref }}` through `env:` instead of interpolating it into `run:` (PR #16 review, docs/pr-suggestions.md P9) — from T-0032
- [ ] Dead "detect not green" override in `scripts/ci_gate.py` removed or covered by a test (PR #18 review, P9) — from T-0032
- [ ] Workflow lint (`actionlint` or equivalent) passes on the changed workflows — from T-0032
- [ ] `.github/` README or `docs/WORKFLOW.md` updated — from T-0032
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
