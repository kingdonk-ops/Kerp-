## Goal
The screens to raise and run Requests for Inspection in the web app, for internal users and for client representatives (PER-15) (quality-and-inspection.md §`inspection_requests` 4, 9–13).

## Acceptance criteria
- [ ] Register (Execution group): filters discipline, status, date range, anchor, "mine"; columns RFI no. ("Draft" when none), discipline title, date, slots, status; opens the detail
- [ ] Create/edit draft: discipline, shift, slots (up to the discipline's `max_slots`) with inspection type, date and time in the project time zone, duration, location/batch label per discipline, linked ITP lines/ITRs picked from the anchor tree, extra anchors, party points (prefilled; a changed point asks for a reason and shows `POINT_DIFFERS_FROM_ITP`)
- [ ] Issue shows the `NOTICE_SHORT` warning and other findings before confirming; the allocated RFI no. is shown after issue
- [ ] Detail: header, slots with status, result and reschedule notes, history from the event table, comments by party, PDF download; actions shown only to allowed personas (§12) — confirm, reschedule (new time, reason, cause party), attendance per party, waive a party (waiver ref), witnessed/no_show/failed (reason code), cancel; 409 conflicts reload the record with a message
- [ ] PER-15 view (client web app/PWA): only visible slots; confirm, reschedule (cause fixed to client), waive their own party, comment; never sees delay records, `cause_changed` history entries or a cause party (e2e asserts none on the PER-15 detail and history)
- [ ] Internal delay panel on the detail (cause party, hours, status; cause change for PER-02/PER-06)
- [ ] Every string through `t()`; generated API client updated (`npm run gen:api`)
- [ ] e2e: draft with two slots → issue (number shown) → PER-15 confirms one slot → reschedule the other with history visible → record witnessed and no_show → delay shown internally, not to PER-15 → PDF downloads
- [ ] Docs updated
- [ ] (product intake 2026-11-21) The detail screen shows, beside the slot state, one line per external party: party, point (H/W), attendance, so the reason a slot is still open is visible (§inspection_requests §11 'Why a slot is open'); the notice-delivery column is shown only once T-0350 has landed
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
