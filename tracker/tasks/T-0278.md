## Goal
While a request carries an impersonation token, the actions the spec reserves for the real person can never run, whatever endpoint is added later (ADR 0015, diff §4.2 *Support impersonation*).

## Acceptance criteria
- [ ] One central enforcement point, not per-endpoint code: (1) `ProjectAccess` built for an impersonation principal never contains `A` or `S` and `can_release_hold` is false (T-0010 tiers), so every authority check denies; (2) a route-level classification `impersonation=allow | forbid` attached through a shared dependency / route marker, enforced by one middleware-level dependency that answers **403 `IMPERSONATION_ACTION_FORBIDDEN`** before the handler runs
- [ ] `forbid` covers at least: password set/change/reset confirm, PIN set/reset, device enrol/revoke/wipe, admin-grant and membership changes, project creation, access-request and invite decisions, team changes, runtime and deployment settings, impersonation start (no nesting), every endpoint that needs `A` or `S` (sign-off, signing ledger T-0119, client co-sign, inspection submit/approve, hold release, override decisions) and every `/api/v1/admin/*` mutation
- [ ] Fail-closed default: a **mutating** route (POST/PUT/PATCH/DELETE) without an explicit classification is `forbid`; under the TD-426 planner default (c) every mutating route except `/auth/impersonation/exit` and `/auth/logout` is `forbid`
- [ ] Contract test enumerates `app.routes` and fails on (a) any mutating route that is not classified, (b) any route in the protected list above, or declaring an `A`/`S` requirement, that is classified `allow`; the test names the route and tells the author how to classify it; later modules (T-0119, inspections, holds) are covered automatically
- [ ] Every refusal is written to the ledger as `impersonation.denied` (admin, target, route template, method), rate-limited per session (one entry per route per minute)
- [ ] Error code in the shared error catalogue with an i18n key
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
