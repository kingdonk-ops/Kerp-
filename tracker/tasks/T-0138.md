## Goal
ADR 0003 §5: the ingestion wizard (T-0107) works from a saved, versioned mapping profile so each
client's spreadsheets import without code.

## Acceptance criteria
- [ ] `oe_asset_import_profile` + revisions (`BaseRecordMixin` + project RLS): header synonyms → target (level key, node field, `custom_fields` path, item type), tree mode (`parent_row`, `path_column`, `column_per_level`), update-by-ID mode, per-column value parsers (asset-and-tagging.md §Import mapping profiles)
- [ ] Saving creates a new revision; an import records the revision it used
- [ ] Targets are validated against the project's level defs and field registry on save (unknown level key or field → 422)
- [ ] Profiles can be exported/imported as part of a client pack (consumed by T-0108)
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
