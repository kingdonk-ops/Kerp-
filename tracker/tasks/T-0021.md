## Notes
The spec has no detail on headers or log format, so these are provisional defaults. Sign-off is requested in **TD-022** (spec-gap). Details are in `backend/README.md`.
- Request id: pure ASGI `RequestContextMiddleware` (`app/core/request_context.py`). An incoming `X-Request-ID` is honoured only if it is 1-128 chars of `[A-Za-z0-9._-]`, otherwise a uuid4 is generated. The id is echoed on every HTTP response and stored in the `request_id_var` contextvar (`get_request_id()`). Websocket and lifespan scopes pass through untouched.
- Logs: stdlib `logging` + `JsonFormatter` (`app/core/logging.py`). No new dependency, so structlog was not needed. Each line has timestamp/level/logger/message/request_id plus `extra=` fields. `kerp.access` writes one line per request (method, path without query, status, duration_ms). Headers are never read for logging. uvicorn's access log is disabled because it prints query strings. `configure_logging()` runs from `create_app()`, is idempotent, and leaves foreign handlers alone. New setting: `KERP_LOG_LEVEL`.
- Unhandled exception before the response starts: it is logged on `kerp.error` with the traceback and request id, and the client gets a generic JSON 500 that carries the request id and security headers. The exception is not re-raised, so uvicorn does not log it a second time. In debug mode it is re-raised so Starlette's traceback page still works. If the error happens after the response has started, it is logged and re-raised.
- Security headers: pure ASGI `SecurityHeadersMiddleware` (`app/core/security_headers.py`). Headers a route sets itself are kept. The CSP comes from `KERP_CONTENT_SECURITY_POLICY` (default `default-src 'none'; frame-ancestors 'none'`). HSTS `max-age=31536000; includeSubDomains` follows `KERP_HSTS_ENABLED`; when that is unset (the default), HSTS is on only in production. `/docs`, `/redoc` and the OAuth2 redirect get a relaxed docs CSP because the strict CSP would break Swagger UI.
