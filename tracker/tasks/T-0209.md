## Goal
Phase 2 exit e2e: prove a weld **cannot** be accepted outside the qualification/NDE rules, and the
full happy path can.

## Acceptance criteria
- [ ] `welder.assign` with an expired / out-of-range qualification is blocked with a visible finding (R-WPS-2/3)
- [ ] `weld.accept` with a missing or `reject` NDE result, an unreleased ITP hold, or an open NCR is blocked (R-WPS-4)
- [ ] Happy path: approved WPS + valid in-range qualification + all NDE `accept` + ITP released → weld reaches `accepted`
- [ ] Playwright journey runs green in CI
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
