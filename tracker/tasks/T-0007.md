  - Writes now need the exact scope (edge spec §6), which supersedes the "visible/writable" rule in the first note. `project_isolation_policy` is `FOR ALL` with `tenant_id = current_tenant AND project_id IS NOT DISTINCT FROM current_project` in USING and WITH CHECK. A project session can no longer create a tenant-level row, demote a row to tenant level, or update or delete one.
