## Goal
The unauthenticated capture API of ADR 0013 with its security controls as acceptance criteria.

## Acceptance criteria
- [ ] No JWT: tenant from `KERP_DEFAULT_TENANT_ID`, project from the decoded token, session bound to that project only; the hash looked up under normal project RLS (no `SECURITY DEFINER`, no bypass); a contract test proves the public router reads nothing outside the token's project
- [ ] Invalid, tampered, expired, revoked, inactive, exhausted, cross-project tokens and a disabled project all → the same 404 body; no metadata (label, project, template) leaks; constant-time compare (tests)
- [ ] `GET /`: pinned template revision with localised strings, pre-bound anchor header (code, description), and only the allowed lookups: fleet asset numbers + descriptions of selectable equipment and/or display names of active members; never e-mails, phones, user ids or internal ids (opaque per-response handles) (tests assert absent keys)
- [ ] `POST /uploads/presign`: T-0016 presigned upload scoped to the link's project and the inspections module, short TTL (`presigned_url_ttl_minutes`), size ≤ `max_upload_size_mb` (T-0230), at most N files per submission (planner default 20); files become `available` only after the ClamAV scan (T-0218); the stub scanner is refused for public uploads (test)
- [ ] `POST /submit`: answers validated by the template's CEL rules (T-0110) on the server; creates the inspection with `source = "public_link"` (new `RECORD_SOURCES` value, ADR 0013), `public_link_id`, `submitted_by_display_name`, optional `submitter_contact`, client IP, user agent; `submission_count` incremented atomically against `max_submissions`; idempotency key suppresses duplicates; runs T-0180 automations
- [ ] Per-client-IP rate limits (trusted-proxy client address, T-0068) on GET, presign and submit, plus per-link daily caps; 429 with `Retry-After` (tests)
- [ ] Abuse and spam controls: honeypot field, answer count and string length limits, payload size cap, `Referrer-Policy: no-referrer`, `Cache-Control: no-store`, token path segment scrubbed from access logs and Sentry
- [ ] Audit: each submission and each rate-limit refusal is a T-0006 ledger entry with `source = "public_link"` (refusals without the token)
- [ ] IP and user agent nulled after 90 days by a batch job (planner default, TD-410)
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
