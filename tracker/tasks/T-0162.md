## Goal
Co-sign mode (i) (online, own account and PIN; user R1a). No client PIN hash or other client secret ever goes to an inspector's device (user, 2026-11-13).

## Acceptance criteria
- [ ] A PER-15 sets and resets a 6-digit signing PIN online; only an Argon2id hash is stored, in a new identity table `oe_identity_signing_pin` (`BaseRecordMixin` + tenant RLS), not on the core user table (planner default)
- [ ] `POST /api/v1/signing/cosign-tokens` (username or e-mail + signing PIN + inspection id), called from the inspector's session, returns a single-use co-sign token for that inspection valid 5 minutes (planner default); a signer who is not an active PER-15 member of the project with the anchor in their granted subtree → 403
- [ ] Rate limit and lockout are server-side per signer, whichever device calls: 5 wrong PINs lock co-sign for that signer for 15 minutes, 10 until the signer resets the PIN online (planner defaults); tests from two different devices share the counter
- [ ] No endpoint, pull-delta or export returns the PIN hash; a test asserts the pull scope contains no signing-PIN data
- [ ] Identity `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
