## Epic
Every register (asset / work-anchor register first, then scaffolds, scope changes, plan lines,
inspections, NCRs, equipment/credential registers) can show **any column** — core, level or
item-type `custom_fields`, ancestor levels, child rollups, cross-module lookups through
service column providers, CEL computed — and can be filtered by any column (AND/OR filter AST
compiled against a whitelist), grouped with totals, and saved as private / team / project /
portal views. Columns are added and removed by the user; new field defs appear without a
deploy (ADR 0003). Reference: the front-end planning workbook columns and its summary sheet.
T-0020 (storage) and T-0025 (RegisterPage shell) stay the foundation; this epic covers the
rest (column catalogue + providers, filter compiler, grouped/aggregated views, conditional
formatting, sharing, bulk actions, export/import with the same column ids).

**Status `needs-breakdown`:** the planner agent splits this into S/M tasks (`T-xxxx`, `epic: E-01-01`) when its phase is next. Do not implement an epic directly.
