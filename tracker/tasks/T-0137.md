## Goal
ADR 0003 Amendment 7 and TD-107: a changed client pack is offered to existing projects, never
forced; project copies keep a `derived_from` link instead of inheriting.

## Acceptance criteria
- [ ] Each item a pack copies into a project (level def, terminology entry, item type, template, numbering pattern, register type, mapping profile) records `derived_from` = pack key + version + item key (asset-and-tagging.md §Client packs)
- [ ] When the pack gains a version, `GET /projects/{id}/config-packs/{key}/updates` lists new / changed / removed items with a diff; nothing changes until accepted (Amendment 7)
- [ ] Accepting an item applies only that item; a change that would re-key an existing level is refused (409)
- [ ] Compare view API returns the project copy against its `derived_from` source (TD-107)
- [ ] Rule-set upgrades are handled by T-0036 (not duplicated here)
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
