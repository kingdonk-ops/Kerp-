## Goal
Bulk tag ingest (Excel/CSV/IFC) via `POST /assets/import` → SAQ job → atomic `/apply`, driven by a saved import mapping profile (T-0138), with the parsing safeguards of ADR 0003 §5, dedup and Rev A→0 revision tracking.

## Acceptance criteria
- [ ] Import runs as a SAQ job then applies atomically (`/apply`)
- [ ] The wizard maps through a saved mapping profile (T-0138) and supports all three tree modes (`parent_row`, `path_column`, `column_per_level`) and update-by-ID (asset-and-tagging.md §Import mapping profiles)
- [ ] Identifier columns are read as text (`101.1`, `0012` unchanged); a date-typed cell in an identifier column is flagged as a row warning
- [ ] `#N/A`-style error cells become nulls with a row warning
- [ ] A multi-value cell (`101.1 and 101.3 ; 102`) splits into several anchors
- [ ] A dry run returns per-row errors and warnings before apply; apply is refused while errors remain
- [ ] Duplicate tags detected and merged, not re-created
- [ ] Revision bump (Rev A→0) tracked on re-ingest of an existing tag
- [ ] `asset_management` `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
