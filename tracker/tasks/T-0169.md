## Goal
TD-218 (processing): uploaded video and audio are checked on the server before they count as complete.

## Acceptance criteria
- [ ] After `complete`, a `batch` SAQ job probes video/audio files for container, codec, duration and size against the T-0167 limits
- [ ] The probe library has a permissive licence (no GPL), is imported lazily inside the job (T-0022 lint updated if it is a new heavy lib), and its licence is recorded in the module README
- [ ] Out of limits → attachment `rejected` with a reason, the uploader is notified; until the probe passes the attachment is not `complete`, so submit fails with `ATTACHMENTS_INCOMPLETE`
- [ ] No server transcoding
- [ ] Tests with small synthetic media files (generated in the test, no real client data)
- [ ] `uploads` `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
