## Epic
Register every scaffold (number, location node + description, type, duty, dimensions, design
ref, erected by/when, handed over and approved by, custodian, notes, files from other scaffold
programs, PDFs, Word docs, photos), track it through request → erect → tag → re-inspect →
modify → dismantle, and link it to assets, RSWs, plan lines, tasks and permits. Each scaffold
owns an Item so tag inspections are one-engine inspections. A scheduled job creates the
re-inspection task before the interval expires, notifies the custodian (or auto-assigns an
inspector by rule), and marks the tag invalid when overdue — which fails the AWP scaffolding
gate and planner readiness. Field users scan a QR to see status and request inspection.
Full detail and suggested breakdown in the spec §12.

Open decision: TD-082 (re-inspection interval, triggers, auto-assignment).

**Status `needs-breakdown`:** the planner agent splits this into S/M tasks (`T-xxxx`, `epic: E-04-13`) when its phase is next. Do not implement an epic directly.
