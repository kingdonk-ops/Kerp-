## Goal
TD-161 (16a + d) and TD-044: the Android app that Pilot-0 runs on, sharing the web frontend.

## Acceptance criteria
- [ ] Capacitor project wraps the existing frontend; `minSdkVersion` 30 (Android 11); target SDK current
- [ ] CI builds a debug APK on every PR touching `frontend/` and a signed release AAB on `dev`; signing keys come from CI secrets, none in the repo
- [ ] Release is distributed through managed Google Play / MDM only (documented; no public listing, no side-loading instructions)
- [ ] Network access only to the deployment's API origin; Android backup of app data disabled (`allowBackup=false`)
- [ ] A smoke e2e (emulator or Capacitor test runner) signs in and opens the shell
- [ ] `frontend/README.md` documents the build
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
