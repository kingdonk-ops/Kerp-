## Goal
The calibration hard quality gate (edge spec §3). `oe_equipment_asset` tool register +
immutable `oe_equipment_calibration_cert` history ledger. Calibration PDFs upload via
presigned URL; an ARQ worker runs OCR (Tesseract) to extract serial/cert no/cal date/expiry
and matches against the asset. Match → cert `verified`, prior cert `superseded`, tool
`active`, expiry updated. Discrepancy → cert `discrepancy_flagged`, tool `quarantined`,
QA-lead task, inspection selection blocked. When an ITP is rendered, only tools with
`status='active'` AND `calibration_due_date >= CURRENT_DATE` are selectable; a submission
referencing an expired/invalid tool fails server-side with `ERR_QUALITY_GATE_EXPIRED_TOOL`.
This is a backbone capability feeding the `eligibility` service (T-0111).
