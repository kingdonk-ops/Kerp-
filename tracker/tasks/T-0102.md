## Goal
The asset-schema half of the one engine (SPEC-11 §3): extend `oe_asset_type` (`parent_type_id`, `schema_version`, `status_set_id`, default ITP/inspection template refs), `oe_item_types_attr_registry` (auto-merge same label+type), `oe_item_types_status_set` mapping to the neutral lifecycle enum. Attributes use the **same field registry as `forms`** (T-0110). Default ITP/inspection template ids are references resolved through the `forms` service, not cross-module FKs. Values stored relational + JSONB, GIN-indexed (ADR-001).
