## Goal
The critical gate that ends Phase 1 and freezes the backbone contract before Phases 3–6
build on it (edge spec §7.1). The spec labels this gate `T-0131`; that id is already the
forms-templates task, so the tracker uses this next free id. A CI test gate asserting three
invariants:
1. **Schema immutability:** no column on `oe_asset_node` / `oe_asset_item` may be modified
   or dropped without an accepted, peer-reviewed ADR (`docs/decisions/ADR-xxxx.md`).
2. **CEL evaluator conformance:** the shared corpus (≈120 mathematical/logical expressions)
   runs across Python (`celpy`) and TypeScript (`cel-js`) asserting exact parity of results
   AND error codes (consumes the T-0110 fixtures and the T-0132 TS package).
3. **Seam verification:** the service contracts for `run_checks`, `eligibility` and the VFS
   routing resolver are hash-checked to block unapproved signature drift.

## Acceptance criteria
- [ ] Schema-immutability test fails CI on an unapproved column change to the two core tables; passes when an ADR is present
- [ ] CEL parity suite (full shared corpus) runs both runtimes and fails on any result/error-code divergence
- [ ] Seam hash-check test pins `run_checks` / `eligibility` / VFS-resolver signatures and fails on drift
- [ ] Gate wired into `ci-gate` so Phase 1 cannot be declared frozen while red
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
- [ ] Module/README.md and docs updated
