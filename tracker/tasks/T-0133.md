## Goal
Implement ADR 0005 (accepted 2026-11-10): `oe_field_checkout` lease (user, device, expiry, per-record base_revision, pinned template_revision_id), checkout/release/force-release endpoints, office edits to field-owned values of a checked-out record **blocked (409), not queued**, and the per-field sync-back contract (spec §8, §11 tests 11, 13–15). The P6 re-import half of the contract (tests 10 and 12, change-impact report) is T-0166, outside Pilot-0 (user, 2026-11-13, R2a).

## Acceptance criteria
- [ ] `oe_field_checkout` with BaseRecordMixin + project RLS; one active checkout per record; `POST /sync/checkouts`, `DELETE /sync/checkouts/{id}` (release, supervisor force-release) (p6 spec §8.1, §10)
- [ ] Office write to a field-owned value of a checked-out record → 409 naming the holder; nothing is queued for later application — after release the office user re-submits (ADR 0005 acceptance; p6 spec §7)
- [ ] Expired lease: data is accepted if nobody else checked the record out; otherwise it goes through the conflict-log path, never dropped (p6 spec §8.5)
- [ ] Test 11: tablet path owned by `p6` → `ERR_FIELD_NOT_OWNED` for that path, rest applied
- [ ] Test 13: force-release + office edit, then stale tablet sync → server value kept, tablet value in `sync_conflict_log`, review item raised
- [ ] Test 14: signed-off inspection not changed by a later tablet sync; Test 15: `client_op_id` replay is a no-op
- [ ] `sync` `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
