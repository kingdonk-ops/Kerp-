## Goal
Make the PostgreSQL + RLS backend run (14–25 min, serial, every test migrates up and down on the
one shared `kerp_test` database) as fast as the SQLite run after T-0081, while keeping every test
on real, committed PostgreSQL with RLS exactly as production gets it.

## Acceptance criteria
- [ ] Once per test session the owner role builds two templates: `kerp_tmpl_migrated` (upgrade head + fixture tenants seeded) and `kerp_tmpl_empty` (extensions only, as `infra/postgres/initdb` creates them); nothing stays connected to a template
- [ ] Each test that needs a migrated database gets its own `CREATE DATABASE … TEMPLATE kerp_tmpl_migrated`, dropped at teardown (`WITH (FORCE)`); tests that run migrations themselves (`test_migrations.py`, revision-targeted upgrades) copy `kerp_tmpl_empty`
- [ ] `tests/db_support.py:database_url()` and `tests/audit_support.py:tamper()` point at the per-test database (runtime role `kerp_app` for the app, owner for tamper); RLS, REVOKEs, ledger triggers and grants come from the template unchanged
- [ ] Database names are unique per xdist worker; the PostgreSQL job runs `pytest -n auto --durations=25`
- [ ] CI Postgres runs with `fsync`, `synchronous_commit` and `full_page_writes` off, set by an `ALTER SYSTEM … ; SELECT pg_reload_conf()` step (service `options` cannot pass server flags)
- [ ] The 90 % coverage floor moves to the PostgreSQL run (`--no-cov` removed there); the SQLite run keeps running the full suite without it or with it, recorded in Notes
- [ ] `make test-pg` / `make test-pg-all` still work locally against docker-compose (the owner role can create databases)
- [ ] **Not** done: per-test SAVEPOINT/outer-transaction rollback (rejected 2026-11-21: `SET LOCAL` context would leak across units of work, the side-write pool and `tamper()` cannot see uncommitted rows, concurrency tests need real commits)
- [ ] RLS bypass (T-0007), frozen migration DDL (T-0033) and CEL conformance (T-0017) tests unchanged and green; no test skipped, xfailed or weakened
- [ ] `backend/README.md`, `docs/WORKFLOW.md` updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
