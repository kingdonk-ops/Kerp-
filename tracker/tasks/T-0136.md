## Goal
ADR 0003 §3 and Amendment 6: level and domain nouns are data, so a CUI user never sees "RSW".

## Acceptance criteria
- [ ] Terminology packs stored per project and per client pack: key → values per locale (at least `en`, `de`) with plural categories (asset-and-tagging.md §Terminology packs)
- [ ] `GET /projects/{id}/terminology?locale=xx` returns the resolved map (project → client pack → default); cached per project and invalidated on change
- [ ] Frontend `t()` resolves terminology keys (`level.*`, `doc.*`) through the layer before the locale bundle, with plural selection by count; switching project switches labels
- [ ] Test: a `cui-line` project renders "Line" / "Job Pack" in nav, column headers and breadcrumbs and never "RSW"; a `remediation-rsw` project renders "RSW"; `de` values are used under the German locale
- [ ] All new user-visible strings go through `t()`
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
