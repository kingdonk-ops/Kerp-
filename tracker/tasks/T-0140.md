## Goal
ADR 0004 Amendments C–D and TD-070 on the unified inspection record.

## Acceptance criteria
- [ ] `inspection_date` (user-entered) and `entered_at` (server) stored on every inspection (quality-and-inspection.md §Unified inspection record, Dates)
- [ ] `inspection_date` more than `backdating_threshold_days` (project setting, default 7) before `entered_at` requires a non-empty `backdating_reason` (422 otherwise) and sets a `backdated` flag exposed in the report payload (Amendment D)
- [ ] `run_checks` context carries `inspection_date`; the server re-runs the checks on submit and validity rules evaluate as of that date (Amendment C)
- [ ] Project setting `allow_self_approval` (default false): the performer approving or supervisor-signing their own inspection → 403; with the setting true → allowed (TD-070)
- [ ] Inspections can only be soft-deleted (`deleted_at` + audit-ledger entry); no hard-delete path exists (TD-070)
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
