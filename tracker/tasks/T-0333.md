## Goal
The RFI slot state machine after issue (quality-and-inspection.md §`inspection_requests` 4, 5, 12–14): confirmation, the reschedule back-transition that keeps history (TD-045), witness attendance and outcomes, and the witness check that stops an ITR being submitted before its external hold/witness point is satisfied.

## Acceptance criteria
- [ ] Confirm `requested → confirmed` by the named witness or a PER-15 of the client party whose subtree holds every slot anchor; PER-06/PER-07 may record it on behalf only with `confirmation_ref` (`confirmed_via = recorded_on_behalf`); others 403 (tests)
- [ ] Reschedule `requested | confirmed | no_show | failed → requested` with a future time, non-blank reason and cause party (PER-15 → always `client`): event keeps old and new `scheduled_start`; `reschedule_count` + 1; confirmation, attendance and `reminder_sent_at` cleared; notice recomputed from now; a closed request reopens; linked records stay `INSPECTION_REQUESTED` with `planned_start` moved; from `witnessed | waived | cancelled` → 409 (tests)
- [ ] Attendance per external H/W party: the named witness may record their own `attended`; PER-06/PER-07 record `attended | absent` (tests)
- [ ] Outcomes per §4: `witnessed` needs every external H/W party attended or waived and ≥ 1 attended; `waived` by PER-15 of the party (any point) or PER-06 for `W` only with `waiver_ref`; `no_show` only when `outcome_occurred_at` ≥ start + `no_show_grace_minutes` (default 30) and ≥ 1 party absent; `failed` needs a reason code (tests for each, incl. PER-06 waiving an `H` point → 403)
- [ ] `witness_status(inspection_id)` returns `not_required | none | pending | satisfied | not_satisfied` per §5: `no_show` with only `W` parties absent after valid notice → satisfied; `H` absent, short notice or `failed` → not satisfied (tests)
- [ ] `construction_control` adds the locked system-default rule `WITNESS_REQUIREMENT` to `inspection.submit` using `witness_status` and the ITP line's external H/W points: findings `RFI_REQUIRED`, `WITNESS_PENDING`, `WITNESS_NOT_SATISFIED`; per-record override (ADR 0004 Amendment A) allowed for `W`, refused for `H` with 422 `OVERRIDE_NOT_ALLOWED` (tests); a record without external H/W points is never blocked (test)
- [ ] Comments from both sides (`party` from the author's persona), append-only, ≤ 2,000 characters; PER-15 only on slots they can see (tests)
- [ ] Every transition is a conditional update on `version` + `status`: the second of two concurrent actions gets 409 (test); each writes an event (with `on_behalf_of_user_id` / `delegation_id` columns, filled by T-0293) and a ledger entry; each runs `run_checks(context, "inspection_request.<action>")`
- [ ] Offline outcome: attendance + `witnessed | no_show | failed` accepted as a queued mutation with client op id and diff §6.4.1 time evidence; at sync the §4 rules run on the reconstructed `occurred_at`; a slot no longer `requested`/`confirmed` fails the mutation with `SLOT_STATE_CHANGED`, nothing applied, inspector notified (tests)
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
