## Goal
The server publishes the client-visible limits so field and web clients can stop using literals (diff §4.7 Client bootstrap). API only; the client consumption is T-0248 (phase 1, needs the client storage contract of T-0127).

## Acceptance criteria
- [x] `GET /api/v1/settings/client`: any signed-in user; only `client_visible` entries (offline window, grace, clock skew, media size/duration caps, annotation cap); never deployment config or secrets (test)
- [x] The OpenAPI schema describes the response so `npm run gen:api` can generate the client (regenerated and committed if the frontend exists); consumption by the clients is T-0248
- [x] ETag / `Cache-Control: no-store` per the auth rules; unauthenticated → 401
- [x] Module `README.md` and docs updated
- [x] All quality gates green (see CLAUDE.md §Quality gates)

## Notes
- 2026-11-21 (planner): Created from the pasted task 'T-0075' (runtime system settings registry) (item 3). Path `/api/v1/config/client` of the paste → `/api/v1/settings/client` (the settings module's mount).
- 2026-11-21 (planner, PR #137 review round 1): Split: this phase-0 task is the API only and depends on T-0230 alone; the client half (fetch at sign-in and sync, client storage contract, limit checks) moved to phase-1 T-0248, which depends on T-0127.
- 2026-11-21 (implementer): `GET /api/v1/settings/client` returns `{"values": {key: value}}`, the effective values (`service.client_values`, with the request's deployment config so caps apply) of the `client_visible` entries of the caller's tenant. A map, not fixed fields, so entries declared later (media caps T-0167/T-0169, annotation cap T-0156) join without a schema change; the OpenAPI schema types the values (bool | int | number | string | int[]). Today four keys: the three `offline` entries and `max_upload_size_mb`.
- 2026-11-21 (implementer): No written "auth rule" on ETag exists; default taken (TD-516): `Cache-Control: no-store` plus a strong `ETag` (SHA-256 of the canonical JSON of the values); `If-None-Match` matching (or `*`, weak compare) is 304 with no body and the same headers. Unauthenticated is 401 before any validator check.
- 2026-11-21 (implementer): `npm run gen:api` with the locked backend deps also drops the Decimal `pattern`s that the committed `openapi.json` carried (stale generation; `schema.ts` unchanged by it). The drift check is TD-126.
