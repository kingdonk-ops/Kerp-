Give third-party inspectors and lab/NDT subcontractors a least-privilege way in (diff §4.9 *External parties*). Shape depends on TD-435; written for the planner recommendation (a) PER-17.

## Acceptance criteria
- [ ] Persona per TD-435 added to the matrix (edge spec §5.2 amended in this PR) and T-0010's tier mapping: `V` on the granted subtree, `C` only on certificate submissions and witness attendance records, `S` only for witness signatures of points that name the party, never `A`

- [ ] Witness attendance on inspection requests (T-0115, T-0333): an RFI slot party `third_party` can name an external party user as `witness_user_id`; that user sees only the slots naming them (calendar and detail), confirms, records their own attendance `attended` (`absent` is recorded by PER-06/PER-07, as for every party), gets the call-out notifications as a named witness (T-0335) and signs the witness line through the attested sign-off (T-0289) when the point requires it; no access to delay records (internal_commercial) (quality-and-inspection.md §`inspection_requests` 2, 12)
- [ ] Internal-commercial boundary (T-0295) applies; no lobby list (external); access only by invite or PER-09 assignment
- [ ] Tests: party sees only its subtree; cannot approve inspections, release holds or read another party's submissions
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
