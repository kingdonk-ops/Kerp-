- 2026-11-10: Manifest contract: `MANIFEST = ModuleManifest(name, version, depends_on, toggleable, default_enabled)` plus the six required files. Start-up fails with every problem listed (missing file/MANIFEST, name != directory, bad version, unknown or cyclic deps, non-toggleable module depending on a toggleable one, missing `router`). Module routers mount at `/api/v1/<name>` (`_` -> `-`) in dependency order; `modules` is reserved for the toggle API.
- 2026-11-10: Per-project toggle: new table `project_module_setting` (BaseRecordMixin, `project_id NOT NULL`, unique per tenant/project/module, project RLS; additive migration `0003`). Enabled = own setting (row, else `default_enabled`) AND all dependencies enabled; `set_enabled` refuses (409) changes that would break a dependency and audits each change on the project's `project_modules` chain. Every route of a toggleable module gets a gate dependency that answers FastAPI's own `404 {"detail": "Not Found"}` while the module is off for the request's project; requests without a project are not gated. Project context comes from the `DbSession` tenancy binding (T-0007 seam), so T-0008 only has to fill `get_tenancy_context`.
- 2026-11-10: Toggle API `GET /api/v1/modules`, `PUT /api/v1/modules/{name}` (404 without project context). Admin-tier guard deferred to RBAC: TD-129. UI: TD-127. First-insert race on the unique constraint: TD-128.
- 2026-11-10: Shared-file edits kept minimal: `app/main.py` (`create_app(..., modules_package=...)` + one `install_modules` call), `app/core/db.py` (one model import line), `tests/test_migrations.py` (head is now `0003`). A parallel task adding its own `0003` migration must re-number on rebase.
- 2026-11-10: TD-036 resolved: `tests/test_lint_get_db.py` (AST walk; only `app/core/db.py` may name `get_db`). TD-018 resolved: `npm run gen:api` (= `python -m app.openapi` + openapi-typescript 7) with `frontend/src/api/openapi.json` and `schema.ts` committed; CI drift check is TD-126.
