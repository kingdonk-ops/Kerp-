## Goal
Raise an issue from an inspection with the linked-issue-type picker (user, 2026-11-21; issues.md §8): one linked issue type is used directly, several are offered as a pick list, none falls back to the category × type default.

## Acceptance criteria
- [ ] "Raise issue" on an inspection detail (and the approve-as-failed dialog of T-0316) calls `GET /api/v1/issues/templates?for_inspection=` and: single → opens the raise form with that template; pick → shows the linked issue types to choose from; none → pre-selects the default and allows the T-0318 type/category choice
- [ ] The raise form is the T-0318 form with anchor, or project-level with location and links for a project-level inspection (T-0329), and `source_inspection_id` set
- [ ] Audit inspections show the origin fixed by the audit scope (read-only)
- [ ] All strings through `t()`; component tests per branch; e2e: inspection with two linked issue types → pick → issue raised and linked
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
