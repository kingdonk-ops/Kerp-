## Goal
The management half of public capture (ADR 0013, proposed): links are created and revoked by authenticated project staff.

## Acceptance criteria
- [ ] `oe_inspections_public_link` (`BaseRecordMixin` + standard project RLS): `template_revision_id` (standalone template only, else 422), `category` (default `safety_prestart`), `anchor_node_id`, `anchor_item_id`, `equipment_id` (at most one; each nullable), `token_hash` (unique), `label`, `allowed_lookup_scopes` JSONB (default `{"equipment": false, "staff": false}`), `expires_at` (null only with `is_permanent = true`), `max_submissions`, `submission_count`, `is_active`, `created_by_user_id`; index `(project_id, is_active)`
- [ ] Token = base64url(project id ‖ 32 random bytes) shown once in the create response (ADR 0013 §2); only SHA-256 stored; never logged (log scrub test)
- [ ] `POST/GET /api/v1/inspections/public-links`, `POST /{id}/revoke` (immediate), `POST /{id}/rotate`: PER-06 or PER-09 of the project only, others 403; another project's link → 404
- [ ] Create, revoke and rotate are T-0006 ledger entries (never the token)
- [ ] Project setting `public_capture_enabled` (default false) switches every link of the project off
- [ ] A permanent-links list for periodic review
- [ ] Module `README.md` and docs updated
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
