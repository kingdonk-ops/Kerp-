## Goal
FastAPI application factory, typed settings, health endpoint.

## Acceptance criteria
- [x] App factory (`create_app()`) returns a configured FastAPI app; app boots
- [x] Typed settings via pydantic-settings loaded from env (no hardcoded config)
- [x] `GET /health` returns 200 with JSON `{status, version}`
- [x] All quality gates green (see CLAUDE.md §Quality gates)

## Notes
- Layout: `backend/app/main.py` (`create_app(settings=None)`, run via
  `uvicorn app.main:create_app --factory`), `app/core/config.py` (`Settings`,
  cached `get_settings()`), `app/api/health.py`, empty `app/modules/` package reserved
  for domain modules. No module loader / DB / auth (later Phase 0 tasks); TD-001
  (port vs rewrite core) left open.
- Settings: env prefix `KERP_`, env vars only (no `.env` file read), frozen.
  `environment` is `Literal["development","test","production"]`. `database_url` /
  `redis_url` declared as optional, `repr=False` (credentials never logged); unused here.
- `/health` version = `Settings.version`, defaulting to the installed `kerp-backend`
  distribution version (single source: `pyproject.toml`), overridable by `KERP_VERSION`.
  `/health` is liveness only — no DB/Redis probing (readiness belongs with the DB task).
- Coverage floor set at 90% (`--cov-fail-under=90`, branch coverage); current 100%.
- Gates also verified under Python 3.12 (CI version) via a throwaway uv venv.
- Follow-up: TD-016 (httpx -> httpx2 for Starlette TestClient deprecation warning).
