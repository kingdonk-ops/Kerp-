## Goal
Stop outbound URLs (which can carry tokens) reaching the JSON logs, and apply the TD-022 decision that API docs are not exposed in production. Covers TD-024 and the docs part of TD-022 (user decisions 2026-11-09).

Also close the logging/config review notes (PR #7, #9; absorbed from T-0064): JSON logs that cannot fail on a non-UTF-8 console, client disconnects not logged as 500, and no `debug=True` in production. All of this lives in the same files (logging setup, settings, app factory).

## Acceptance criteria
- [ ] `httpx` and `httpcore` loggers set to WARNING in the logging setup; a test proves an INFO request line with a query-string token is not emitted — TD-024
- [ ] In production, `/docs`, `/redoc`, the OAuth2 redirect and `/openapi.json` return 404; available in dev/test (setting overridable); `npm run gen:api` still works in dev
- [ ] backend/README.md updated (TD-022 values: no HSTS preload, docs hidden in production)
- [ ] TD-024 resolved in the same PR
- [ ] `JsonFormatter` output cannot fail on a non-UTF-8 console (e.g. `ensure_ascii=True` or an encoding-safe stream handler); tested — from T-0064 (PR #7, #9 review)
- [ ] A client disconnect (`asyncio.CancelledError`) in the request-context middleware is logged as a disconnect (e.g. status 499), not 500; tested — from T-0064 (PR #7, #9 review)
- [ ] Settings validation refuses `debug=True` with `environment=production` at startup; tested (absorbs the relevant part of TD-124) — from T-0064 (PR #7, #9 review)
- [ ] All quality gates green (see CLAUDE.md §Quality gates)
