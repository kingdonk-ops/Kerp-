T-0057 defers the magic-link lookup, eligibility check, token store write, e-mail and refusal audit to a FastAPI post-response task (diff §4.2 allows a SAQ job or a post-response task). If the API process dies between the 202 and the task, that one request is lost and the user asks again. Moving it to the SAQ interactive queue needs a core enqueue hook installed by the jobs module (like app/core/mail/queue.py), since core never imports app.modules.
