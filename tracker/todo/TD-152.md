resolve_request_scope (app/core/auth/access.py) reads auth_project_membership in a tenant-level session before the request session is bound. If T-0014's stricter policy limits membership rows to projects in app.allowed_project_ids, the resolver sees nothing and every request loses its allowed list (fail closed, but broken). Add a clause such as user_id = app.current_user_id (bind the user setting) or resolve via a SECURITY DEFINER function.
