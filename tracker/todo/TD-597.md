T-0227's POST /api/v1/mail/templates/{key}/{locale}/test-send queues an ordinary send through send_mail (recipient_user_id = the caller); mail_send_log has no marker, so test sends count in GET /stats for that template, and the test-send rate limit counts every e-mail the caller queued to itself (created_by = recipient_user_id = caller). A later additive column (e.g. kind = transactional | test | broadcast, shared with T-0228) would let stats exclude test sends and make the limit exact.
