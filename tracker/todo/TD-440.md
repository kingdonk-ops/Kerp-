Enterprise roadmap 2026-11-21, item 8 (user-approved assessment). IP allowlisting is infrastructure configuration, documented in `docs/deploy/network-access.md` (AWS WAF IP sets on the load balancer / CloudFront, Entra Conditional Access named locations for SSO users). KERP keeps no allowlist table. Revisit if a contract requires per-project or per-persona IP rules that the WAF cannot express (e.g. external accounts only from the client's ranges); that would need a spec change and an ADR (request IP is trustworthy only behind `FORWARDED_ALLOW_IPS`).
