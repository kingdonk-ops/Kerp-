T-0101 creates the core table that T-0131 freezes. Chosen where the spec is silent: name (String 255, nullable; the spec lists no name column but ADR 0003 §6 binds context.level('asset').name); 'planned dates' as planned_start / planned_finish (DATE); budget_qty / budget_hours / earned_qty as NUMERIC(18,4), uom String(32); superseded_by / derived_from as JSON lists of node ids; field_schema_id as a plain UUID (the FK comes with the registry, T-0102); display_code renders '' for a {level_key} the path has no node of; display_path joins codes with ' / '. The external keys, discipline_code and planned dates exist as columns but the T-0101 API does not write them (P6 import T-0105/T-0106, ingestion T-0107). Retired nodes (status, T-0134) are not yet excluded as parents or from work_anchor_for. Confirm names and types before the M1 freeze.
