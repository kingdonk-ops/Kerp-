The paste (T-0180) creates tagout_confirmation / repair_request / supervisor_review follow-ups in oe_inspection_follow_up 'or the tasks module E-04-07 later'. E-04-07 (Phase 4) is needs-breakdown. Planner default: T-0257 owns oe_inspections_follow_up in the inspections module behind a service API (open/confirm_tagout/resolve/cancel, has_open_blocking(target)). When E-04-07 is broken down, the planner decides whether follow-ups become generic tasks (additive, with the blocks_return_to_service flag and the equipment.activate provider kept) or stay a specialised record linked to tasks.
