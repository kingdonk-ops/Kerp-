T-0349 made app.core.digest.sha256_hex the one helper for the token digests (field, password_reset, sso, devices, admin invites). Three inline compositions remain: core/auth/lockout.py (subject key), core/mail/addresses.py (normalised address) and modules/admin/service.py (normalised e-mail); each is hashlib.sha256(x.encode()).hexdigest() of a normalised value and can call sha256_hex(normalise(x)) with the same output. The audit hash (core/audit/hashing.py, domain-separated bytes) and the settings ETag / overrides canonical hashes are different shapes and stay.
