---
id: TD-064
title: Lookup fields must bind to a typed item + attribute and snapshot values at inspection time
kind: spec-gap
status: open
tasks: [T-0110]
source: planner
raised: 2026-11-10
---

Legacy ITEM_SELECTOR fields are filtered by item-type uuid and render a display template like '{{Cert No. / Lot No}} - {{Batch Certificate Received}}'; compliance scripts then parse that display string (indexOf('yes'), split(' - '), dd/mm/yyyy parsing), so editing a display template silently breaks validation. One variant hard-codes master data in the template script. Specify: lookup field = item-type filter + stored item id + snapshot of named attributes (cert received, VOC held, calibration expiry) at completion; CEL reads the typed attributes; no master data inside templates.
