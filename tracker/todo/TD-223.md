Repo review 2026-11-13 (needs validation A). review-gate is the only review requirement on dev (0 approving reviews, scripts/setup_github.sh). T-0067 stops a PR from rewriting the gate, but agents act as the owner login, so the marker itself does not separate principals.

Update (T-0067): the gate script now runs from the PR base, but `pull_request` workflows run the
PR's own copy of the workflow file, and any PR-added workflow can emit a check named
`review-gate`. Closing that needs a GitHub-level control, e.g. a ruleset "require workflows to
pass" pinned to `dev` (if the plan supports it), or CODEOWNERS on `.github/` + `scripts/` with
required code-owner review (needs a second human, since GitHub forbids approving your own PR).
