T-0012 stores `oe_projects_project.spatial_bounds` as PostGIS `geometry(Polygon,4326)` and validates GeoJSON shape, closure and coordinate ranges in the schema. Not done: (1) a GiST index for spatial queries (add when the first spatial query lands, e.g. asset/defect pins inside the site); (2) an `ST_IsValid` check (self-intersecting rings are accepted); (3) the unique `(tenant_id, code)` also counts soft-deleted projects, so a deleted project's code cannot be reused (a partial unique index `WHERE deleted_at IS NULL` would allow it).
