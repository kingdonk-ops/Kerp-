ADR 0016 (accepted, user 2026-11-21) lets a system_admin read and administer project-scoped records of every project in the tenant without a membership. Writes stay attributable exactly as today (created_by/updated_by on the row, created_by on every ledger entry, the admin's device id). Reads are not ledgered for anyone today, and the user's text asks only for attribution 'as today'. Planner default (applied, not blocking): no per-read ledger entry; the admin console endpoints of diff §4.7 keep their per-call audit entries; the structured request log already carries user id, route and project id. Question for the user: do you want an access log of non-member system_admin reads (e.g. one ledger entry per admin per project per day, 'admin_project_access', in the tenant chain admin-system:<tenant>), for client-confidentiality evidence? It would be additive (no policy change) and can follow later.
