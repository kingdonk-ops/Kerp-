T-0223 exposes the hold's reason, setter and time only in the `PUT /admin/system/projects/{id}/legal-hold` response; `ProjectRead` has just `legal_hold`. The project admin page (T-0225) therefore shows on/off only. A `GET` on the same path (system_admin only) would let the System admin see why and since when a project is held. Until then the reason is in the audit log (`admin-system:<tenant>`, event `legal_hold_set`).
