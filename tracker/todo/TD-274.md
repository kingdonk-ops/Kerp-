T-0039 enforces 'the last System admin cannot be removed' for grant revocation. T-0014's user deactivation does not check it: a System admin can deactivate their own or the last other System admin's account, leaving no active System admin. Add the same guard (409) to deactivation in T-0039 or a follow-up.
