T-0036 offers per-rule updates for sets the project already has a copy of, and copies brand-new system sets into the tenant layer on deploy (so new projects get them). An existing project with the module enabled has no copy of a set added later; run_checks resolves the tenant set (live, not a copy), so the project cannot edit it until a copy exists. Add an offer 'new rule set available' (accept = copy_module_defaults-style copy) and list it in the drift report.
