The paste (T-0188) wants project-editable CEL rules in the ADR 0004 store mapping work-anchor / asset / task attributes to an approved ITP template. None of the existing kinds fits: check returns block | warn, notify and digest take an event, p6_eligibility is P6-only. Planner default (applied, not blocking; ADR 0004 Amendment H, planner, pending this TODO): kind itp_assignment, engine cel; variables anchor (node: code, level key, roles, custom_fields), item (nullable: item_type, custom_fields), activity (nullable: activity_code, discipline, task type from the linked P6 activity / task), project, params; action assign with params.template_key (a template key, not a revision id, so a new published revision is picked up; the latest published revision is used, never a draft); rules evaluate in sort_order and the first match wins; editors like check (PER-06 project, PER-13 tenant), so PER-09 never decides which ITP applies. Must land before the M1 freeze (T-0131) or as a post-freeze amendment. Question for the user: confirm.
