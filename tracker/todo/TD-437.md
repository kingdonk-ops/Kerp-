Enterprise roadmap 2026-11-21, item 4 (after Pilot-0; spec diff §4.9 *SCIM provisioning*; ADR 0017). Planner defaults applied, not blocking:

1. **Users only.** `/Groups` is not supported (ServiceProviderConfig says so); Entra groups never map to personas or grants (diff §4.5).
2. **Create** is allowed: SCIM creates an account with no credentials, no memberships and no grants; `is_internal` is derived as usual (§4.1). Access still comes from invites, PER-09 assignments and team links.
3. **Deprovision:** `active = false` (PATCH/PUT) or `DELETE` deactivates (`is_active = false`, never a hard delete) and revokes every live session at once (T-0244's revoke). Devices are not revoked or wiped (an offline outbox is kept and drains only after a fresh sign-in, which a deactivated account cannot do); a System admin may still revoke devices.
4. **Last active System admin:** deactivation is refused (409 SCIM error), audited, and every System admin gets an in-app notice.
5. **Matching:** `externalId` = Entra object id, linked like an SSO link (an account linked to a different oid → 409); `userName` = e-mail, case-insensitive; reactivation (`active = true`) restores sign-in but not sessions.
6. **Tokens:** shown once, 256-bit random, stored as a hash, default lifetime 365 days (max 730), rotation keeps the old token valid for 24 h.
