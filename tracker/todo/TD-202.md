Planner defaults for TD-120 decision 3a (user, 2026-11-13), applied in KERP-CONSOLIDATION-AND-DIFF.md §4.1 and T-0040/T-0041: (1) entering an exact project code shows that one project (code + name) and lets the user file an access request decided by the project's PER-09 holders; the existing project code is a human-readable identifier, not a secret, so it never grants access on its own; (2) users who already have projects can open the lobby from the top-bar picker ('Find a project'), not only users with none. Confirm or change (e.g. a separate secret join code that grants a default persona directly).
