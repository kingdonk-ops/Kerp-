---
id: TD-574
title: "Mail history exact-address lookup puts the address in the GET query string: load-balancer/proxy access logs (e.g. ALB) would record it"
kind: risk
status: open
tasks: [T-0226]
source: implementer
raised: 2026-11-22
---

GET /api/v1/mail/sends?address= hashes the address server-side and KERP's request log never records query strings, but an ALB or reverse proxy in front of KERP that writes full-URL access logs would. Options: a POST search body for the address lookup (T-0229 UI would use it), or a deployment rule (docs/deploy) that access logs drop query strings. See ADR 0020 (alternatives).
