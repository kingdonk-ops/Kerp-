TD-228 (user, 2026-11-13) gives each team-project link a role, e.g. Editor on project A, Viewer on project B. KERP's project roles are the 15 personas of edge spec 5.2 (T-0010): there is no internal read-only persona (the only V-only tier is PER-15 Client Representative, which is also a signatory) and no generic 'Editor'. Planner default applied to T-0013/T-0073 (does not block): a link carries exactly one persona code, like an individual membership; allowed are PER-01..PER-14 except PER-09 (Project Administrator stays an individual assignment, so a team link never confers admin and never needs the PER-09 SoD warning) and PER-15 (client signatory, individual only); a PER-07 link names its site (site_node_id), same check as memberships. Options: (a) keep the default; (b) add a read-only internal persona (e.g. PER-16 Project Viewer, tier V, single scope) to the edge 5.2 matrix, an additive change T-0073 can pick up; (c) allow PER-09 via team links with the SoD warning on the link.
