validation.seed_project(session, project_id, source_pack=...) copies the chosen pack's tenant sets at project creation, but the project record does not store the chosen pack and projects.create_project passes none. copy_module_defaults (module first enabled) therefore copies base sets (source_pack NULL) only. T-0108 (client packs) should persist the project's pack and pass it to both. Also decide how a pack set overrides a base set with the same key (the unique (tenant, project, layer, key) constraint means pack sets currently need their own keys).
