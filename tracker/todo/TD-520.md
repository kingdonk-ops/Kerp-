scripts/review_gate.py accepts patch-id=<7..40 hex> and compares by prefix, so a 7-character id (28 bits) approves any diff whose patch-id starts with it. Fix: require the full 40-character patch-id in new markers (keep reading old ones only if needed) and compare exactly; update the reviewer agent instructions and tests.
