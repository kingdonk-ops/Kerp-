`backend/app/core/auth/entra.py` `EntraJwks.key_for` (~l.288-311): the lock is held across `_load()`; when the first load fails `_loaded_at` stays `None`, so every following callback refetches without going through `store.claim` (the once-a-minute limit). Add a short negative cache or route the initial load through the same limit. From the PR #114 review.
