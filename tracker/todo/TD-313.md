app.core.auth.access.persona_holders lists users holding a persona on a project from auth_project_membership. Once ADR 0008 / T-0073 adds team-derived grants and drops deactivated users in load_grants, persona_holders must apply the same rules, or a team-derived PER-06/PER-02 is never routed an override (and a deactivated user still is).
