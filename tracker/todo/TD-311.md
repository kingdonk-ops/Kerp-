Migration 0021 (T-0040) revokes EXECUTE on the two SECURITY DEFINER lobby functions from PUBLIC and grants it to CURRENT_USER, the role running the migrations (kerp_app in CI and dev). A deployment that runs migrations as a separate owner role must GRANT EXECUTE on both to the runtime role, else the lobby list and code lookup fail (fail closed). Same handling as TD-275. Because the definer in CI is the RLS-bound app role, the functions raise app.is_system_admin transaction-locally for their own three-column read and restore it; with a BYPASSRLS owner that step is redundant but harmless. Re-check both when TD-056 lands.
