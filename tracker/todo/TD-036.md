A bare Depends(get_db) has the default yield scope, which commits after the response, so a commit-time failure returns 200 for a rolled-back write. Add a grep-style test or lint rule (like T-0022's heavy-import check) that fails when get_db is used outside db.py except via DbSession. Fits T-0007 or the module loader task (T-0011).
