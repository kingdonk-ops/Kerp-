ADR 0002 ports Inspection-ERP `core/reporting` (reportlab PDF, openpyxl Excel) for sign-off certificates and inspection-request notices. Neither library is in `backend/pyproject.toml` `banned-module-level-imports` (T-0022), so the lazy-import rule is not yet enforced for them. Whichever of T-0115/T-0119 ports the renderer first adds them to that list, in the same PR. No spec doc names reportlab; the choice is recorded in ADR 0002.
