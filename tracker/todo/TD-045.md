User clarification (2026-11-09, answer to TD-014):

- **RFI = Request for Information**, a separate module.
- The **Request for Inspection** is part of the scheduling/notification system. The user said it "should be kept as a record in the Request for information system". It is a record of booking/scheduling an inspection and goes with the completed ITP and report. Each inspection can be linked to its inspection request time.
- Title and layout differ by discipline: **mechanical**, **coating** or **civil** inspection notification.
- Fields: contract number, project, relevant ITP number, scheduled inspection date, scheduled inspection time, RFI no., requested by (name + email), inspection type (task specific), hold point or witness point, asset details, RSW number, job location or batch number, inspection result, rescheduled / other status, comments from both KAEFER and the client.
- Multiple inspections can be scheduled on the same day; requests can be rescheduled.
- Shown on a calendar in the client portal, the main portal and the tablet app.
