The pasted audit explorer filters 'by event type such as sod_warning, device_revoked, clamav_quarantine, setting_changed'. Ledger rows (T-0006) carry chain_key, payload, created_by, device_id; event names are not standardised (sod_warning is a payload flag, devices write to device:<id> chains, settings to deployment-settings:<tenant>).

Planner default (T-0222): filter by chain-key prefix (entity type) and, where present, a payload key 'event' or boolean flag; new writers from T-0218..T-0242 put an 'event' key into their payloads. A standard event catalogue for all writers is the open spec question (hash format unchanged: payload content only).
