Product intake 2026-11-21, item 26. Fast ITR capture for repetitive checklists is not specified for the capture screen (T-0165). Planner defaults (user to confirm), for the screens acceptance criteria of T-0165 or a follow-up task:

- Large result buttons (pass / fail / N/A and the template's result options) with number-key shortcuts on keyboards (1, 2, 3 …), 48 dp targets (diff §6.3).
- Filter tabs with live counts: all / unanswered / failed / flagged (comment or conflict flag).
- Progress per section (answered / total).
- Canned comments per template or project with placeholders filled from the record (item code, value, limit), inserted then editable.
- "Clone last": copy the previous answer of the same question in this record's repeat group, or the last record on the same anchor (only fields the template marks clonable; never signatures or photos).
- Speed mode: walk unanswered items only, advancing after each answer.

All strings through `t()`; offline as the rest of the capture screen. Must keep the 300-question form-open budget (diff §6.3).
