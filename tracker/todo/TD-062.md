Legacy templates are sections -> checks, each check one of: LIST (repeating rows of fields with a printed summary table), FORM (single record) or TABULAR (cell grid with row/col spans, used to replicate paper ITRs). Checks carry: pass/fail/N-A buttons with confirmation text, allowed + default issue types, minimum photos, issues must be closed before completion, carry values/issues over on re-inspection, repeat per child component, print/page-break options. Template level: applicability (item category + types), inspection category, stable uuid + revision + DRAFT/APPROVED. The forms schema in ADR 0002 / EDGE-SCREENS 2.2 covers sections and fields only. Spec owner: state which layouts and check settings KERP supports.

- 2026-11-10: Decision (user, 2026-11-10): LIST and FORM layouts now, GRID later; first-class hold points (TD-063) remove most grid needs. Planner writes the spec.
