DynamicForm renders template labels, option labels and validation error_message as authored (EDGE-SCREENS 2.2 schema has single-language strings). UI chrome goes through t(); template content does not. Decide whether templates carry per-locale strings (e.g. label: {en: ..., de: ...}) or a translation-key convention.

- 2026-11-13: Decision (user, 2026-11-13): 11a. Template strings accept a plain string or a per-locale map ({en: ..., de: ...}) with fallback to the template's default language. Only English is used for now (TD-172).
