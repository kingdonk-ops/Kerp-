From the PR #88 round-1 review (T-0036). pending_updates on a set whose parent layer has no default set (e.g. a set the project or tenant created itself) raises the reset error, so the API answers 409 'no ... default set ... to reset to'. For the TD-280 updates badge an empty offer (or an updates-specific 404) is a better answer; the reset wording is misleading here.
