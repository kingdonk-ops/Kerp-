The Settings screen (T-0232) labels entries from the i18n catalogue (`admin.settings.entries.<key>`,
`admin.settings.categories.<category>`, `frontend/src/i18n/locales/en.ts`). An entry or category
without a label still shows, by its key, with the server's (English) description as hint. Each
task that declares a registry entry (T-0140, T-0156, T-0162, T-0167, T-0169, T-0174, T-0277,
T-0289, T-0306 feature flags, T-0308) should add its label in the same PR so the screen stays fully
translated.
