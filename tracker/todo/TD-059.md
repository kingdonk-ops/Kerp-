Migration 0002 revokes UPDATE, DELETE, TRUNCATE from PUBLIC and from the migrating role and adds append-only triggers. When migrations and runtime use separate roles (TD-056), the runtime role must not be the table owner (an owner can re-grant, disable the triggers or drop the table) and the deploy must grant it SELECT, INSERT only, and the app could refuse to start if app.core.audit.guard.ledger_guard_problems reports anything.

- 2026-11-10: Decision (user, 2026-11-10): Build into the AWS deployment task (T-0004): runtime role SELECT, INSERT only on audit_ledger, not owner; refuse start if ledger_guard_problems reports anything.
