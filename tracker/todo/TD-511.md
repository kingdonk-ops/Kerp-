Since T-0230 the seven T-0044 settings live in oe_settings_value (migration 0037 copied the rows). oe_settings_deployment and its DeploymentSettings model are kept but nothing reads or writes them. Dropping the table is a destructive migration (CLAUDE.md §6): write the ADR, then remove the model, the table and the legacy constants that only describe it.
