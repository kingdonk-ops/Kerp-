T-0075 AC defines the expected state as every non-deleted link of a non-deleted team over its members, without mentioning the linked project's state. The teams service never syncs a link whose project is deleted (it revokes, README 'Links to a deleted project', TD-358). Reconcile follows the service: such a link expects nothing, its leftover rows are reported as excess (not orphan, the link id is known) and --fix revokes them. Otherwise reconcile --fix would recreate access on a deleted project that the next team change revokes again.
