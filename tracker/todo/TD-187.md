Seen on PR #42's CI (job 131756751263): `tests/test_jobs.py::test_a_cancelled_or_timed_out_job_is_marked_failed` failed with `('running', None)`. In `backend/app/modules/jobs/worker.py` `run_job`, `_start` commits `status=running` in a thread; if SAQ cancels the task (timeout) while `await asyncio.to_thread(_start, ...)` is still returning, the `CancelledError` is raised outside the inner `try`, so the row is never finished. The test polls for `running` and cancels at exactly that point, so it is timing-dependent. Fix in `fix/jobs-cancel-during-start`.
