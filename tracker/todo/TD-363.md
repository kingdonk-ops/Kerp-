T-0077 requires tokens and new passwords scrubbed from logs and Sentry. The JSON log formatter scrubs them now; KERP has no Sentry SDK or DSN setting yet, so only the hook exists: `app.core.logging.scrub_sentry_event` (a `before_send` / `before_breadcrumb` function, tested). Whoever adds the error tracker must install it and set `send_default_pii=False`, and add a test that a failing `/auth/password-reset/confirm` event carries no `token` / `new_password`.
