Backend (T-0277): the impersonation token comes from POST /admin/users/{id}/impersonate, has no refresh token and must stay in memory (never localStorage, IndexedDB or the offline store; ADR 0015 §2). The SPA must not record the last-used project (T-0042) while impersonating (§7). POST /auth/logout with the impersonation token ends only the impersonation (like /auth/impersonation/exit) and keeps the admin's refresh cookie; T-0280 should decide whether the Logout button while impersonating exits only or also signs the admin out (then call logout again with the admin's own token).
