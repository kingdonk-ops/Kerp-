The user's pasted T-0181 asked: "If PER-06 uploads it directly, they may verify immediately." That conflicts with the queue's separation-of-duties rule (nobody decides an item they submitted unless the project allows self-approval, T-0140) and with the no-self-approval default (TD-070).

Safe default applied (PR #139 review round 1; T-0181, T-0260, T-0261, T-0265, quality-and-inspection.md §Non-QA upload routing): a QA reviewer's own upload creates a pending item like any other, decided by a different QA-authority holder. It is auto-verified only when the project's effective `allow_self_approval` (T-0140) is true, and is then flagged `self_approved` in the ledger.

The user can switch a project to auto-verify by setting `allow_self_approval` for it (T-0140); no code change is needed. Not blocking. Question for the user: confirm the default, or ask for a QA-specific auto-verify switch separate from `allow_self_approval`.
