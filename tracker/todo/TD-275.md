Migration 0015 revokes EXECUTE on the SECURITY DEFINER function kerp_caller_admin_grants() from PUBLIC and grants it to CURRENT_USER, the role running the migrations, which is the app role in CI and local dev (kerp_app, TD-056). A deployment that runs migrations as a separate owner role must GRANT EXECUTE ON FUNCTION kerp_caller_admin_grants() TO the runtime role, else every login resolves is_system_admin=false (fail closed, but no System admin can act). Belongs with the deployment task that handles TD-059.
