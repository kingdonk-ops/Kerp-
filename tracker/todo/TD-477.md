asset-and-tagging.md §Endpoints and T-0101 name POST /assets/nodes/{id}/move. The loader derives the prefix from the module name (asset_management -> /asset-management) and, until TD-122 binds the project from the request, every project-scoped router takes the project in the path. T-0101 built /api/v1/asset-management/projects/{project_id}/nodes/{id}/move (and /level-defs, /nodes, /nodes/{id}/work-anchor). Decide: keep these paths and amend the spec, or add a prefix override to the loader so the module answers under /assets.
