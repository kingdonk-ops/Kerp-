Seen 2026-11-22 at desktop width on `/backbone/projects` (Projects list card, admin projects page built by T-0026): the "Visible in lobby" checkbox renders as a large empty square with no visible check mark and no checkbox styling, so the user cannot tell whether the project is visible in the lobby.

Likely cause (to confirm): the native checkbox gets `className="size-touch"` (48 dp glove target, T-0046) and is scaled to 48 × 48 px without its own checkbox styling. The same pattern is used on other admin checkboxes (`SystemGrantsPage`, `MembersPage`, `SystemSettingsPage`, `personas.tsx`), so they may show the same defect.

Fix: keep the 48 dp touch target on the label (or a wrapper) and render a styled checkbox with a visible checked state (and focus ring) in the default and the outdoor high-contrast theme (T-0046, diff §6.3: WCAG 2.1 AA, text ≥ 7:1 in outdoor). Test: checked and unchecked states are visually distinct (component or Playwright screenshot / computed-style check) in both themes; the axe check stays green.
