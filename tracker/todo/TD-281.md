Implementer reading (T-0036): offer read = whoever reads the set (any project member; PER-13/PER-01 on the tenant layer); accept and Try it = the set's editor per §7 (check: PER-06 project / PER-13 tenant; other kinds: PER-09 / PER-01), so PER-09 never accepts a check update; drift report = PER-13 or PER-01, limited by RLS to their portfolio projects. removed_by_project is listed when the project deleted its copy and the default changed since the copy (its version is newer than the copy's origin_version; not necessarily since the delete); once listed it stays in the offer until the set is reset. A system set shipped for the first time is copied into the tenant layer by sync_system_defaults (no tenant choice to keep), changed sets are only offered. Routes use the set id (as T-0034's), not the key.
