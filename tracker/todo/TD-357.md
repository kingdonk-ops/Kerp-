T-0013 makes admin list teams in depends_on because the T-0014 member list names the team of every team-derived grant through teams.service. All modules under app/modules are always loaded today, so this costs nothing now. If a deployment ever removes the teams module (after unlinking every team, as the teams README documents), the admin manifest would fail the loader. When a per-deployment module set exists, make the fill-in optional (e.g. a registry hook the teams module installs, like register_admin_grant_lookup).
