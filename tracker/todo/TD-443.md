issues.md §3/§8. The user kept the T-0116 rule: raising resolves work_anchor_for and a path without a work anchor answers 422 (TD-113). Site audits and condition-survey inspections may sit on nodes whose path has no work anchor, so an automatic create_issue there would fail. Planner default: manual raise stays 422 until a work-anchor node is picked/created; create_issue on such a path is logged skipped (NO_WORK_ANCHOR) and the reviewer + QA authority are notified to raise it manually; the inspection result is not rolled back. Alternative: allow issues whose template has completion_effect=none (e.g. internal audit) without a work anchor. Not blocking.
