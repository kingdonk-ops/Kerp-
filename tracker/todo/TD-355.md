title: Magic-link eligibility ignores project soft-delete unless memberships were revoked with it (core cannot read the projects table)

status: open
tasks: [T-0057]

magic_link_eligible reads PER-14 through access.load_grants, which filters soft-deleted membership rows but cannot see whether the project row itself is soft-deleted (module table; core never imports app.modules). projects.delete_project revokes every membership, so the normal path is covered (tested). A project soft-deleted any other way (script, future restore/undo flow, team-linked project once T-0013 unlinks teams) would leave live PER-14 rows that still count. Options: a core project-liveness hook registered by the projects module, or an invariant test that every project soft-delete path revokes memberships.
