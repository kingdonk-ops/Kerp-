The pasted layout groups files under files/assets/<asset_code>/<work_anchor_code>/{reports,photos,attachments}. The hierarchy has configurable levels; work anchors to a work-anchor node (at most one per path), inspections anchor to any inspection_anchor level or an Item (ADR 0003, CLAUDE.md §6).

Planner default (T-0235): files/tree/<code of each node from the root to the anchor node, one folder per level>/[<item code>/]{reports,photos,attachments}; codes made file-system safe (ASCII, reserved characters replaced, collisions suffixed with a short id), with the mapping in archive_manifest.json. Confirm with the user if a fixed asset/work-anchor layout is preferred.
