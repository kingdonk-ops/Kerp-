T-0077 provides the policy and the one set-password API (`app.core.auth.service.set_user_password`, `set_password`, `create_user(password=...)`), used by the self-service reset. No endpoint exists yet for a signed-in user to change their password (current password + new one), and the admin API creates accounts without a password. When those are built they must call `set_user_password` (policy, NFKC, session revocation) and decide whether the caller's own session survives the change.
