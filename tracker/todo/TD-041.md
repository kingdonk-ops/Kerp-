`tests/contract/conformance_fixtures.json` pins every known divergence as a fixture with a
`known_gap` block (runtime + actual result). The harness asserts the pinned result on the
deviating runtime, so a library change is noticed. 11 gaps remain (7 server, 4 client).

**Fail-closed contract (every caller, incl. `run_checks` / T-0018):** a CEL gate passes only on
`CelOk(value=True)` (Python: `isinstance(r, CelOk) and r.value is True`; TS:
`r.ok && r.value === true`). Every error and every non-bool result blocks.

Closed in T-0017 (server overrides in `backend/app/core/cel/strict.py`, now parity fixtures
under `strict.*`): mixed int/uint/double arithmetic, `int / double`, IEEE NaN/-Infinity for
`x / 0.0`, `&&`/`||` with non-bool operands (absorption kept), string indexing, negative list
indexing, `string(true)`, `has()` on a plain variable, literal non-bool `&&`/`||` operands and
macro predicates.

Remaining server (celpy) gaps:
- **Fails open — fix first:** `gap.filter_non_bool_predicate` — a non-literal non-bool
  `filter()` predicate keeps every element (celpy uses Python truthiness; macros are hard-wired
  in celpy's evaluator, not in the overridable function table). Same truthiness applies to
  `exists_one()`. celpy also has non-standard `reduce()`/`min()` macros the client lacks.
- Fails closed (error instead of a value, or a different error code):
  `gap.heterogeneous_ordering_literal` (`1 < 2.0` errors; int on the left of a mixed ordering),
  `gap.eq_null_on_value` (`x == null` errors instead of false),
  `gap.all_every_element_errors` / `gap.exists_every_element_errors` /
  `gap.ternary_condition_error` (no-overload instead of the element error),
  `gap.macro_wrong_arity` (`all(x)` gives INVALID_ARGUMENT instead of NO_MATCHING_OVERLOAD).

Remaining client (cel-js) gaps: `uint(-1)` is INVALID_ARGUMENT not INT_OVERFLOW; intermediate
int64 overflow is not detected (the wrapper only range-checks the final result); `has()` on a
map literal is rejected; an int-keyed map result looks string-keyed.

Options: subclass celpy's evaluator for macros, upstream fixes, or restrict the Designer's CEL
subset with authoring-time type checks. T-0131 needs exact parity on 120 expressions (currently
240 parity fixtures).
