frontend npm run test runs the *.a11y.test.tsx suites in headless Chrome so axe measures real layout and Tailwind CSS (jsdom has no layout: contrast and target size cannot be measured there). No browser is downloaded; GitHub ubuntu runners ship Google Chrome at /opt/google/chrome/chrome. If a runner lacks it, add 'npx playwright install chromium' to the frontend job or set KERP_CHROME_PATH.
