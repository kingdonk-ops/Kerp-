User-supplied spec (2026-11-21, pasted task 'T-0073', now T-0221/T-0222) asks for a tenant-wide upload quarantine table and a global audit explorer for system_admin. Diff §4.1: System admins 'read no project-scoped records without a membership like any other user'.

Planner default applied (not blocking): (a) quarantine monitor reads through a narrow, count/metadata-only path like the lobby lookup: project code, file id, size, SHA-256, status, reason code, scanner signature, uploader id, timestamps; the original filename and the linked record only for projects where the admin holds a membership. (b) Audit explorer reads under normal RLS: tenant-level chains in full, project chains only of projects where the admin holds a membership. A wider read needs a policy on a core table (audit_ledger) and therefore an ADR.

Question for the user: keep the defaults, or allow System admins a full cross-project read (with an ADR and an audit entry per read)?
