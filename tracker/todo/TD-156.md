T-0015's jobs API requires an authenticated user and scopes rows by tenant/project (RLS + ORM scope, cross-scope 404), and only kinds registered with api=True can be enqueued. It has no capability-tier check: any authenticated user of the scope can enqueue an api kind and poll any job of the scope. Add a capability per kind (JobKind field) checked through the RBAC API from T-0010.
