Product intake 2026-11-22, item 9. Field teams need to print labels on site: QR / asset tags for Items and nodes, and quarantine labels for equipment and material. Scanning is already specified (Bluetooth handhelds and camera, materials-and-traceability.md; T-0155); printing is not.

Options:
- (a) **Web Bluetooth** straight to a label printer: works in Chrome on Android only, not iPad Safari; printer model must expose a documented protocol.
- (b) **The printer vendor's print service / app** on the device (Android print service or vendor SDK through the Capacitor build, T-0141).
- (c) **PDF label sheet** rendered by KERP (SAQ worker, label size per template) and printed by any printer, including office printers before the shift.

Planner recommendation: (c) first for every platform, (b) for the managed Android tablets once the printer model is known; (a) not relied on. The label carries a reference only (code, QR of the Item/node scan identifier, project code), never a public URL.

Question for the user: which printer model(s) and which device platform (managed Android tablets, iPads, both) do the crews use?

Note (PR #179 review): T-0255 already specifies a printable QR label for capture links; reuse its label rendering.
