Diff §4.1 and T-0052/T-0053/T-0059 name POST/GET /api/v1/projects/{id}/invites, .../{invite_id}/resend and /api/v1/invites/preview|accept. The module loader (T-0011) mounts every module only under /api/v1/<module>, and T-0052 is module admin, so T-0052 serves them as /api/v1/admin/projects/{id}/invites[...] and /api/v1/admin/invites/preview|accept (next to /admin/projects/{p}/members). Decide: keep the admin prefix and update the spec text and T-0053/T-0059 (accept-with-password, setup-preview), or let a module mount routes outside its prefix. The frontend uses the generated client, so only the spec wording and later tasks are affected.
