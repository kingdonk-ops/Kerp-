Product intake 2026-11-22 (3), item 7 (planner default; user to confirm). Spec written: quality-and-inspection.md §Signing attestation, bullet "Competency at signing".

- The `credentials` service (T-0118) exposes a read-only fact for rule sets: `signer.holds_credential(type)` (valid credential of qualification type X for the signer at the signing time, `as_of` = the sign-off's `occurred_at`), plus the level when the type has levels (TD-099).
- Sign-off rule sets (for example `itp.hold_release` for a torque or bolting line) can require it; the fact is evaluated by `run_checks` like any other, never a hard-wired check.
- Each credential the rule set read is snapshotted into `credential_snapshot` of the attestation (the existing #177 snapshot), so the evidence shows what was valid at signing.

To build: T-0118 (service fact), T-0289 / T-0291 (snapshot of the credentials the rule set read). Related: TD-099, TD-100.
