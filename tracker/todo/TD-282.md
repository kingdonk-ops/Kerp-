T-0043 ships app.core.auth.devices.record_sync(session, device_id, user_id=...) and audit.append(..., device_id=...) but nothing calls them yet: no sync endpoint exists. The offline sync core (T-0126) must call record_sync after every successful push/pull of an enrolled device (so the admin UI shows the real last-sync time before a revoke), pass the mutation's device explicitly when a job replays queued work (current_device_id is only set on the request path), and accept queued mutations only from a session of the same user and device (diff §4.2).
