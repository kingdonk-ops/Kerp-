T-0011's toggle API (GET /api/v1/modules, PUT /api/v1/modules/{name}) requires an authenticated, active user (CurrentPrincipal: 401 otherwise) and a project in the tenancy context (404 otherwise; project binding is TD-122). It does not check any capability: once RBAC lands (T-0010/T-0014), PUT must require the project-admin capability tier (403 otherwise), and GET may stay at the view tier.
