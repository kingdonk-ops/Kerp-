TD-045 spec (quality-and-inspection.md §inspection_requests §9). Clients are used to receiving the RFI as an e-mailed PDF on a distribution list. Diff §4.6 limits every KERP e-mail to project code and name plus a link, with no attachments, and T-0058 sends only to addresses of the caller's choosing with no attachment support.

Planner default (applied in the spec, not blocking): the RFI e-mails (issued, rescheduled, cancelled, reminder) go only to project accounts (named witnesses, the PER-15 fallback, requester, PER-06 copy); they carry project code and name, the RFI no., the discipline title and a link to the request page behind sign-in; no scheduled date/time or location in the body, no PDF attachment, no .ics invite, no addresses without an account.

Options: (a) keep the default; (b) add the scheduled date/time to the body (still no attachment); (c) (b) plus the PDF attached and an .ics invite, still accounts only; (d) (c) plus a per-project RFI distribution list of plain e-mail addresses (needs attachment support in core mail and a portal-scoped link per ADR 0013 / portal-plan-review §1.1 for people without accounts).
