title: PG test templates collide between concurrent runs on one server (kerp_tmpl_*_<worker> ignores the database name)
kind: later
status: open
tasks: [T-0223]
source: implementer
raised: 2026-11-21
---

tests/pg_databases.py names its templates kerp_tmpl_empty_<worker> / kerp_tmpl_head_<worker> (worker = PYTEST_XDIST_WORKER or main), independent of the database in KERP_TEST_OWNER_URL. Two pytest -n auto runs against one PostgreSQL server (parallel agent worktrees, each with its own database) drop each other's templates: a T-0223 run had 1141 errors 'template database kerp_tmpl_head_gw0 does not exist'. CI is unaffected (one run per server). Fix: include the source database name (or a run id) in the template names. Workaround used: PYTEST_XDIST_WORKER=<unique> with -p no:xdist.
