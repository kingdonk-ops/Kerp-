The 2026-11-21 paste (T-0179) lets standalone inspections (pre-starts, equipment checks, fault reports) anchor to oe_equipment_asset. ADR 0003 (law per CLAUDE.md §6): inspections anchor to any inspection_anchor node or an Item; T-0111 enforces exactly one of node_id / item_id. Equipment is neither. ADR 0014 (Proposed) drafts: a nullable equipment_id on oe_inspections_inspection; exactly one of node_id / item_id / equipment_id; equipment_id only for is_standalone records of category safety_prestart | equipment_check | repair_fault; qa_itp and every kind=itp record keep the ADR 0003 anchors; equipment read only through the equipment service; an optional location node does not count as an anchor. Alternative (b): model each vehicle/plant item as an Item (oe_asset_item) under an inspection_anchor node (no ADR 0003 change, but fleet would live in the asset tree). No safe default: T-0250 is blocked until decided. The CLAUDE.md §6 wording would change with (a).
