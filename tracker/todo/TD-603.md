T-0228 records a broadcast opt-out (oe_notifications_broadcast_optout, one live row per user) from the one-click link only. There is no way back: a user who unsubscribed by mistake never gets broadcasts again. A later task: a 'Receive announcements' toggle on the user's own profile (soft-deletes / re-adds the row, audited), and the state shown to the user. Transactional mail is unaffected either way.
