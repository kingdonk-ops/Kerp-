`e2e/tests/admin-communications.spec.ts` sends its broadcast as the first-run System admin, who is shared by every run on a database. CI starts from an empty database, so the step always runs there; a local database that already saw 5 runs in the last 24 h skips the send step (`test.skip` naming this TODO). Fix: the seed (`e2e/seed/seed.py`) creates a per-run PER-09 broadcaster on a per-run project (keyed by the run id, like the QA user) and the journey sends as that user, which also covers the PER-09 own-projects path end to end.
