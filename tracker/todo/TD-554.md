Product intake 2026-11-21, item 35. Client representatives get access to an MDR revision or a report through a share link (portal-plan-review.md §1 magic links for people without accounts; E-07-01 / E-07-04). The link lifecycle is underspecified. Planner defaults (user to confirm):

- A share link is **per person** (one recipient, one link; never a group link) and bound to the shared object and revision.
- **Expiry is a duration stamped at creation** (`expires_at` = created + the project's link duration at that moment). Changing the project policy affects only links created afterwards.
- **Bulk re-expiry** is an explicit admin action that names its count before applying ("Change the expiry of 37 active links?") and is audited.
- **Revoke is immediate** (the next request is refused; cached pages are not served).
- Expired and revoked links answer with **distinct messages** ("This link has expired – ask <sender> for a new one" vs "This link was withdrawn"), without revealing the object.
- No public verification page is implied (documents-and-mdr.md, user decision 2026-11-21); a share link is a scoped access grant to one person, tenant bound per ADR 0013 once decided (TD-410).
