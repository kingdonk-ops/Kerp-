ADR 0004 §3 requires findings to record rule_key + version but the §1 column list has no rule version. T-0018 adds oe_validation_rule.version (1 on add, +1 per edit/delete) instead of reusing the mixin revision (which is the offline-sync base revision), plus a set version (+1 per rule change). oe_validation_finding stores only rules that failed or errored (passes are counted in CheckResult.evaluated, not logged). Confirm both before the M1 freeze (T-0131).
