T-0058 choices within diff §4.6: (1) SES soft (Transient) bounces are logged, not suppressed (SES guidance; a full mailbox would otherwise block reset mails for good). (2) auth_user has no locale column, and core cannot read the settings module's default_locale, so the recipient locale is the caller's argument else KERP_MAIL_DEFAULT_LOCALE (en-AU). (3) The entry point is send_mail(session, template_key, to, context, locale): the session is needed to write the send-log row and enqueue after that unit of work commits. (4) SNS messages are not checked for Timestamp freshness (a replay only re-suppresses an address that bounced).
