The legacy JavaScript customisers fall into four kinds: show/enable, derive a value from a looked-up attribute, blocking validation (cb.showError + return false) and warning-only notices (showInformationDialog + return true). Acceptance limits are literals in code (slump range, concrete and grout temperature ranges, maximum aggregate size, test-equipment calibration not expired). Specify a rule severity field and limits as template parameters that cite a specification clause or approved TQ, so an out-of-spec value can be accepted against a recorded TQ.
