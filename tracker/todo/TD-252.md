In cloud sessions GraphQL returns 403, so new-todo's open-PR check (gh pr list) always prints 'WARNING gh pr list unavailable' and only checks branches. This caused three TODO id collisions in the 2026-11-13 hardening run (TD-228, TD-242/243, TD-247). Fix: list open PRs and their changed tracker/todo files through the REST API (gh api repos/{owner}/{repo}/pulls and /pulls/<n>/files), with a test.
