T-0331 AC asks that self-deactivation is prevented. The T-0014 endpoint refuses deactivation only for the last active System admin (409); a System admin can still deactivate their own account when another admin exists. The Users screen hides Deactivate on the caller's own row, but the client never asserts authority: the admin service should refuse is_active=false for the caller (409, audited refusal) and the screen should explain it.
