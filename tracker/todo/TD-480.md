asset-and-tagging.md: code_pattern = 'optional validation/generation pattern'. Numbering patterns elsewhere use placeholders ({project}-W-{seq:4}); a regex cannot generate. T-0101 treats code_pattern as an RE2 (linear-time) regular expression the whole code must match, checked when a node is created (existing codes are not re-validated when the pattern changes). Decide whether code generation belongs to the level def (and in which syntax) or to the numbering mechanism of T-0108, before the level def shape is frozen (T-0131).
