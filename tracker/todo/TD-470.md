Found while running the T-0101 gates locally (Python 3.13, mypy 2.3.1, SQLAlchemy 2.1.9, pydantic 2.13.5): mypy app reports two [var-annotated] errors in files T-0101 does not touch and that are identical on dev (enabled = set(connection.execute(text(...))...) in audit/guard.py; kinds = session.execute(text(...)).scalars() in admin/service.py). The cause is not isolated: the errors remain with SQLAlchemy 2.1.8 (the version in requirements.lock) and with mypy 2.2.0. Whether CI is affected is not known: its backend jobs install with pip install -e '.[dev]' (unpinned, Python 3.12). Fix: annotate the two variables, and consider installing the dev tools from a lock in CI.
