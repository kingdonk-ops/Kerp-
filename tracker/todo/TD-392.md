Admin → System → Devices (T-0051) lists users (GET /admin/users or GET /admin/projects/{p}/members per PER-09 project) and then calls GET /users/{id}/devices once per user. Fine at pilot scale; a single paginated GET /api/v1/devices/admin (RLS/authority-scoped, with user name/e-mail) should replace it before larger deployments.
