Raised from the PR #142 (T-0083) review. CLAUDE.md §4 says to run `npm run gen:api` and commit it when the API changes, and §6 forbids hand-editing `frontend/src/api/`, but no CI step checks either. (T-0083's skip loses nothing here: the backend jobs never checked it.) Add a step to the `frontend` job that regenerates the client from the backend's exported OpenAPI schema and runs `git diff --exit-code frontend/src/api`, failing with a hint to run `npm run gen:api`. Check first how `gen:api` obtains the schema (it may need the backend exported via `app.openapi` / `scripts`), and keep it inside the frontend job so frontend-only PRs still get the check.
