T-0342's criterion says 'settings validation error'. Settings is shared by alembic env.py and python -m app.modules.onboarding.first_run, which run in production without Redis (docs/deploy/first-run.md step 2), so a model validator would break them. Implemented as app.core.startup_safety.require_redis, called in the API lifespan (the worker already refused without Redis in every environment). Confirm or ask for a Settings-level rule with an opt-out for the CLIs.
