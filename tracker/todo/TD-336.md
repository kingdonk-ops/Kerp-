A failed post-commit enqueue (Redis down) or an expired/lost payload leaves mail_send_log rows queued (the worker marks a missing payload failed only if its SAQ job runs). Add a cron (batch worker) that marks rows queued for longer than the payload TTL (24 h) as failed with error_code 'not_enqueued', per scope like the jobs sweep. Callers (magic link, reset) already answer neutrally.
