T-0025's DynamicForm evaluates visible_if / required_if / validation through a RuleEvaluator seam (default: src/lib/cel evaluate) with a fixed set of data types (text, number, boolean, select, date) in src/shells/form/types.ts. When T-0110 lands, replace the local FieldDataType union with the shared field-type registry and make server-side form validation use the same template semantics (fail-closed, empty-value handling, hidden-field sanitisation, visibility fixpoint).
