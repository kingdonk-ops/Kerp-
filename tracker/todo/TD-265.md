T-0049 makes `is_internal` derived (ADR 0009) and the existing auth request bodies (`/auth/login`, `/auth/magic-link`, `/auth/magic-link/redeem`, `/auth/pin/unlock`) already refuse it with 422 (`extra="forbid"`, tested). The admin user create/update schemas and the admin user list are T-0014 and do not exist yet: when T-0014 adds them it must use `extra="forbid"` (or equivalent) so `is_internal`, `entra_oid` and `entra_tid` are 422, and list `is_internal` read-only, with tests. New users must be created through `app.core.auth.service.create_user`, which derives the flag.
