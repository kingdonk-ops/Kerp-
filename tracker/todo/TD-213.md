Master spec §1 (storage isolation) shows s3://kerp-vault/{tenant_id}/{project_id}/{module_namespace}/{hash}.ext. T-0016 (per the task brief and ADR 0007) uses {tenant}/{project}/{module}/{sha256} with no extension: the key is content-addressed and shared by every file row with the same bytes, while filename and content type live on the row and are applied on download (Content-Disposition / served type). Uploads land in staging/{tenant}/{project}/{file_id} (presigned PUT) and are copied by the verify job to quarantine/{tenant}/{project}/{file_id} before any check (review round 1, TOCTOU fix). Decide: keep this layout and amend the spec, or add the extension (which would split identical bytes uploaded with different types).
