T-0051 shows Admin → Access requests / System to PER-09 holders (from /me/projects) and System admins. MeResponse has no system-admin flag, so the client probes GET /api/v1/admin/grants?user_id=<self> (200 only for system_admin; 403 for everyone else, one extra request per session). Add a read-only is_system_admin to MeResponse and drop the probe.
