Only RevocationUnavailableError is mapped (and per endpoint, see TD-290 / T-0349); other Redis calls (rate limits, mail payloads, job broker) can raise redis.exceptions errors that reach the request-context middleware as 500. Fix: map Redis connection and timeout errors to the same app-wide 503 handler T-0349 adds; tests per path.
