Legacy issue types have: name, code, scope DEFECT|OBSERVATION, short business-key prefix, required photo count, priority on/off, dynamic fields (location, multi-select issue type with 'Other' free text, item count), photo/description text snippets, and a separate close-out form (Default Closeout Form: corrective action). Template fields can auto-raise an issue of a set type and priority when an option is picked (e.g. 'Does not Comply' -> high-priority Bolt Tensioning issue). Specify the KERP issue-type entity, its revisioning, and auto-raise on a field option.
