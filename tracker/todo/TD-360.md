T-0023 creates the first System admin without credentials (no password in the repo, the environment or logs). Today the admin can sign in only with Entra ID SSO (T-0054 links the account by e-mail). The one-time link the acceptance criterion names needs the self-service password reset of T-0077 (single-use expiring link), which is not built yet. When T-0077 lands: either the first-run command issues that reset link for the new admin (queued e-mail, never printed), or the deploy docs tell the admin to use 'Forgot password?'. Until then a deployment without SSO has no way to give the first admin a credential.
