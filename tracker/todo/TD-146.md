The switcher's scope (one project or All-Projects) is client state only. How a request names its working project (header, path segment or token claim) is part of binding the request's project scope (TD-122, T-0010). Once defined: add it in createApiClient (frontend/src/lib/api/client.ts), include the scope in TanStack Query keys, and clear scope-dependent caches on switch.
