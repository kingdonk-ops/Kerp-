The T-0182 addendum covers all approval queues: oe_qms_verification_item, oe_validation_override (T-0035, done; shape frozen at M1 by T-0131) and the inspection follow-ups (T-0191). Adding SLA columns to oe_validation_override after the freeze needs an ADR. Planner default (not blocking): the SLA columns go on oe_qms_verification_item only (as pasted); overrides and follow-ups get their SLA state in a qms-owned oe_qms_sla_state row keyed by (record_type, record_id) without FKs, created and closed through the owning modules' services (validation, inspections), never by cross-module table access (T-0198). Follow-ups keep their own due_at (SLA hours from the post-action). Question only if the user prefers columns on the frozen table (then an ADR).
