Planner default written into KERP-CONSOLIDATION-AND-DIFF.md §4.2 (Offline window) while applying TD-170 decision 14a (user, 2026-11-13), which set the window (tenant setting, default 7 days, maximum 14) but not what happens when it runs out. Default: the app keeps every queued change and stays readable, but refuses new edits until the user signs in online; it never deletes data. Alternatives: keep allowing edits and only warn, or lock the app completely. Used by T-0143.
