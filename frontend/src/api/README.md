# `src/api/` — generated API client

Everything here except this README is **generated** from the backend OpenAPI schema.
Never hand-edit those files (CLAUDE.md §6); regenerate them and commit the result in the
same PR whenever the backend API changes.

| File | Generated by |
|---|---|
| `openapi.json` | `npm run gen:api:schema` → `python -m app.openapi` in `backend/` |
| `schema.ts` | `npm run gen:api:types` → [openapi-typescript](https://openapi-ts.dev) (types only: `paths`, `components`, `operations`) |

```bash
# with the backend virtualenv active (its `python` must be on PATH)
cd frontend
npm run gen:api
```

`python -m app.openapi` builds the app with test settings and no database, so the schema
does not depend on the local environment. Request code can use the types directly, e.g.
`components["schemas"]["ModuleState"]`.
